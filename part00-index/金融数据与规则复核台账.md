# 金融数据与规则复核台账

> 用于记录会随时间变化、依赖来源或容易被误读的数值、规则和案例。台账记录的是复核状态，不代表投资建议或策略有效性。

## 复核原则

1. **原始来源优先**：监管申报、公司年报/财报、交易所规则、官方产品文档；注明URL、报告期/版本、页码或字段、访问日期。二手数据注明供应商，并尽可能交叉核对。
2. **口径先于数字**：记录币种、单位、期间、价格日期、计算公式、调整项、分子/分母定义及数据是否为估计。跨来源比较前统一口径。
3. **固定参数分层**：标记为法规/平台规则、行业惯例、研究参数、教学假设或经特定样本验证的策略条件。不得把惯例或示例值写成普适买卖阈值。
4. **复核时效**：平台费率/合约规则在使用前复核；市场数据随每次分析更新；财报在新报告发布后更新；教学参数在策略回测版本变更时复核。过期条目标记“待复核”，不悄悄沿用。
5. **留痕**：修订记录旧值、新值、原因、来源、日期和复核人；未能核实的数据应移除、改为明确假设或标注未验证。

## 待维护项目

- 交易所/经纪商手续费、最小下单量、合约乘数、保证金档位、资金费结算与强平规则：按具体产品、账户等级、地区与规则版本复核。
- 历史公司指标案例：财年、报表重列、拆股、币种、行情市值日期及数据供应商口径需重新确认。
- 技术指标/策略参数：保存原始行情来源、交易对、周期、时区、参数、预热、信号闭合规则、费用/滑点、样本内外与前视/幸存者偏差检查；未做验证标为“教学示例”。
