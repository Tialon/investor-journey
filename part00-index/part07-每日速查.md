# 每日速查

## 金融基础速查

| 项目 | 基础口径 |
|---|---|
| 产品识别 | 分别问资产是什么、合同权利义务是什么、谁交易/清算/托管；现货不是与所有资产类别互斥的一类 |
| 资金风险 | 名义本金、保证金、权利金和担保资金不同；保证金不等于亏损上限 |
| 期间净损益金额 | 期末权益−期初权益+外部提款−外部入金；权益包含持仓浮动损益及负债，不只看权利金 |
| 复利与恢复 | 期间收益连乘；跌50%后需涨100%才恢复，外部资金进出另处理 |

导航与解释：[[chapter00-金融基础]]、[[section02-cashflow-total-return]]；练习：[[section01-finance-glossary-quiz]]。上式是金额对账，含资金进出时的收益率方法另查绩效评估。

## 每日检查

数据时间与原文→新增事件→账户现金/订单/持仓差异→集中风险→是否触发原计划。无新证据时不必交易；研究与执行用 [[part01-实践工作台]]。

## 公式与口径

| 项目 | 公式/口径 | 必须检查 |
|---|---|---|
| PE | 股价/EPS，或普通股市值/普通股净利润 | 期间、GAAP/调整、基本/稀释、预测来源 |
| PEG | PE/盈利增长百分数 | 20倍PE、增长20%时PEG=1，不用0.20作分母；负增长不作常规解释 |
| 财报筛选FCF | CFO−CapEx | 不是自动等于FCFF/FCFE，检查营运资本、SBC与再投资 |
| FCFF | EBIT×(1−税率)+折旧摊销−CapEx−Δ非现金经营营运资本 | 不重复扣CapEx，匹配WACC |
| 经营DCF | 显性FCFF现值+终值现值 | 终值也折现，另做经营价值到股权桥接 |
| ROE | 归普通股净利润/平均普通股权益 | 期间、负权益、杠杆和一次性项 |
| ROIC | NOPAT/平均投入资本 | 明确现金、租赁、商誉等口径 |
| 股票计划数量 | floor(净值×损失预算比例/每股计划风险) | 跳空可超计划损失，再受集中度和现金约束 |
| 最大回撤 | max(1−单位净值/此前最高单位净值) | 外部资金进出另处理，浮亏与成本不能遗漏 |

不设通用PE、FCF收益率或仓位比例买卖阈值；数值应由具体业务、假设与风险预算决定。

## 期权速查

| 项目 | 口径 |
|---|---|
| Long Call 到期平衡 | K+买入权利金，未计费用 |
| Long Put 到期平衡 | K−买入权利金，未计费用 |
| 合约美元损益 | 每股报价损益×实际乘数×张数 |
| 同标的等效股数 | 合约多头Delta×带符号张数×乘数 |
| Theta粗略损益 | 每日Theta×天数×带符号张数×乘数，其他输入不变且小变动时 |
| 信用垂直价差最大亏损 | (宽度−净收入)×乘数×组数，假设两腿完整、同到期同交割物 |

详见 [[section08-strategy-payoffs]] 和 [[section06-execution-checklist]]。实值不等于盈利，保证金不等于损失上限，Delta不是真实盈利概率，价差保护腿不自动处理短腿指派。

## 虚拟币现货与合约速查

策略完整案例：[[section04-crypto-strategy-playbook]]。费用后保本价需计双边费用与实际资金费，止损移到开仓价未必净保本。

| 项目 | 口径 |
|---|---|
| 现货净数量 | 实际成交基础币数量−以基础币扣除的费用，另查其他资产流水 |
| 线性合约毛盈亏 | 带符号基础币数量×(退出价−入场价)，张数先换算乘数 |
| 反向多头毛盈亏 | 报价币面值×(1/入场价−1/退出价)，结果为基础币 |
| 简化初始保证金 | 名义价值/杠杆，真实要求还含产品档位及费用等 |
| 资金费现金流 | 常见多付空规则下−方向符号×结算名义×已结算费率 |
| 仓位计划上限 | 风险预算/(每单位逆向价差+执行成本缓冲)，再按step向下调整 |

名义与保证金不同，低倍不等于无强平。资金费间隔不固定，未知订单先查询不重发，止损触发不等于成交。详见 [[section05-crypto-checklist]] 与 [[虚拟币交易复盘模板]]。

## 虚拟币技术指标速查

| 指标 | 读法与边界 |
|---|---|
| SMA / EMA | 平均价格/指数平滑，记录周期、输入、初值与预热；交叉会滞后或反复 |
| RSI | AvgGain/AvgLoss的Wilder平滑；超买超卖不保证反转，背离有确认时点 |
| MACD | 快慢均线差−信号线形成柱体；柱体改善不等于金叉，和均线非独立证据 |
| ATR | max(H−L, abs(H−前收), abs(L−前收))再平滑；估风险距离，不给方向 |
| RVOL20 | 完整本根量/前20完整根平均量（不含本根）；不等于买盘净流入或当前深度 |

入场/加仓看当时已闭合证据与总风险；保护单可盘中触发，无需等待所有指标同意。参数为教学口径，完整流程见 [[section06-crypto-indicator-workflow]]，案例见 [[section07-crypto-indicator-cases]]。

## 多周期分析速查

| 层级 | 任务 | 不应混淆 |
|---|---|---|
| 日线/4小时 | 背景、方向候选与重要风险区 | 当前未收盘值不等于确认背景 |
| 1小时 | 结构、失效位、有限期候选与风险距离 | 小周期上涨不等于小时突破确认 |
| 15分钟 | 已有候选的执行触发与可执行报价 | 重复触发不产生新预算 |
| 实时保护/成交 | 处理已有保护与真实仓位 | 不等待大周期或所有指标同意 |

每次决策保存各周期闭合/收到时刻与版本；不把最终大K前填到内部小K。预算、追加次数和剩余保护数量按一个真实仓位统一。完整时间轴及冲突见 [[section04-crypto-mtf-trade-cases]]、[[section05-crypto-mtf-conflicts]]。

## 支撑压力与K线速查

| 判断 | 先核对 |
|---|---|
| 支撑/压力 | 区域上下沿、建立时间、周期与价格源；突破后角色互换仍须验证 |
| 突破 | 负责结构的周期已闭合越过区域，成交量用同周期历史分母 |
| 回踩 | 原区域附近拒绝并恢复，量价配合；缩量不能保证守住 |
| 反转 | 形态位置、后续确认和结构变化；局部反弹不等于日线反转 |
| 退出 | 原保护及时执行，实际成交含费用；不靠新形态放宽风险 |

吞没先说明实体或全部影线；同根同时触及止盈止损时，OHLC不能证明成交先后。完整案例见 [[section05-crypto-price-action-cases]]，反证见 [[section06-crypto-price-action-failures]]。
