# 学习与补充路线

> 按正在做的任务推进，保留成果和验收证据；目录有内容不等于已经掌握。

## 第一阶段：研究一家公司

使用 [[part01-实践工作台]] 与 [[案例分析模板]]，从10-K/10-Q、业务、现金流和竞争开始。完成一页有来源、日期、事实/推断和失效条件的研究卡，再参考 [[chapter00-股票投资]]、[[chapter00-财务分析]]、[[chapter00-商业模式]]。

## 第二阶段：给假设定价

使用 [[chapter00-估值方法]]，核对PE分母和FCF口径，完成经营预测、现金流/折现率配对、股权价值桥接与三情景。输出价格区间和敏感项，不用固定倍数自动判定便宜。

## 第三阶段：把观点转为风险预算

使用 [[chapter00-风险管理]]、[[chapter00-资产配置]] 和 [[chapter00-交易心理]]，算数量、集中度、现金义务与压力损失，开仓前留计划。演练再平衡并复盘偏差。

## 第四阶段：期权与事件

[[chapter00-期权学习]] 现有正文/参考笔记59篇。先验收策略盈亏、实值与盈利差别、交割和Greeks符号，再学习财报及专业交易。完成模拟流程与到期对账后，才能单独评估真实执行条件。

## 第五阶段：数据与辅助工具

先掌握 [[section03-数据清洗]]、[[section04-时间对齐]] 与 [[section04-SEC-EDGAR数据]]，再使用 [[chapter00-AI投资]] 帮助提取证据。回测优先解决公开时间、成本、资产集合和样本外问题，参见 [[chapter00-量化投资]]。

## 虚拟币专项路径

[[chapter00-虚拟币交易]] 覆盖现货与合约34篇。先掌握现货成交、费用币、成本与余额；再学习合约数量、保证金、资金费与强平。先按 [[section04-crypto-strategy-playbook]] 独立核算分档、网格、突破、回调、合约多空、区间和对冲的盈利/失败路径，再演练订单不确定、部分成交、保护单和重启对账。

策略研究与真实执行分别验收；数据、账户或订单证据未知时不自动新增风险。通用知识不绑定具体项目或账户参数。

## 按需要补充

待补页见各模块目录，已保留27个近期可能使用的主题及核心内容。优先补具体任务遇到的缺口；行业页补官方资料和财报证据，税务页先确认适用身份和法域，API页先做只读或模拟验证。

已完成的研究卡、模型检查、模拟记录和复盘才是进度证据；不因文件创建就勾选学习完成。
