# 金融基础术语与自测

## 术语速查

| 术语                 | 一句话理解与易错点                                               |
| ------------------ | ------------------------------------------------------- |
| 资产类别 / 产品结构        | 风险来源与取得权利的方式是不同维度，股票也能成为期权标的                            |
| 基金 / ETF           | 集合投资载体；要穿透看实际资产和策略，不能默认分散或保本                            |
| 现货 / 即期 Spot       | 依市场惯例近期交割的交易方式，不代表与股票等资产类别互斥                            |
| 衍生品 Derivative     | 价值与某种标的/指标相关、按合同产生权利义务的工具                               |
| 远期 / 期货            | 常见远期为双边定制；期货通常标准化、场内交易及集中清算，均要读到期条款                     |
| 永续 Perpetual       | 无固定到期，仍有资金费、保证金与强平等风险                                   |
| 期权 / 权利金           | 权利及其价格；买方支付、卖方收取并承担义务，卖平与卖开不同                           |
| 名义本金 Notional      | 合约计算/暴露的参考金额，不等于实际初始付款或最大损失                             |
| 杠杆 Leverage        | 用较少权益承担较大敞口，必须注明分母和产品公式                                 |
| 保证金 / 担保资金         | 融资或履约所需资产；不是保证亏损不超过该金额                                  |
| 标的多头 / 空头          | 通常指对该标的的正/负方向暴露；期权Long/Short表示买入/卖出合约，Long Put仍可具负Delta |
| Bid / Ask / Spread | 买价 / 卖价 / 两者差；中间价与Last不保证可成交                            |
| 流动性 / 滑点           | 可接受条件下成交的能力 / 实际成交相对参考价格的偏离                             |
| 清算 / 交收 / 托管       | 确认和管理义务 / 转移资金证券 / 保管登记及相关服务，不是同一职责                     |
| 现金流 / 总收益          | 钱进出 / 包含价格与收入及成本的经济结果，收款不等于利润                           |
| 权益 / 已实现与未实现       | 资产减负债 / 已处置、平仓或到期等形成的损益与未处置持仓估值变化；实现不等于已交收或可提现          |
| 复利 / 回撤            | 收益再参与后续计算 / 从此前净值高点的下降，涨跌百分比不对称                         |
| 展期 Roll            | 结束旧合约并建立新合约，旧亏损保留，新仓产生新风险                               |

Call、Put、K、乘数、IV和Greeks的完整释义复用 [[section00-options-glossary|美股期权术语]] 与 [[section02-binance-small-capital|小资金原理]]。来源与边界分别见本模块前三篇，不用速查替代合约规则。

## 自测：先作答，再对照

1. “股票、ETF、现货、期权、券商”是否是五种彼此互斥的资产类别？ETF能否是期权标的？
2. 永续没有固定到期，是否就等于直接持有现货、没有持仓成本？
3. 用100美元保证金控制500美元线性多头敞口，标的下跌10%，忽略费用约亏多少？能据此确定强平价吗？
4. 卖K=100、100股乘数的现金担保Put收200美元，到期S=80被指派，接股款和整体经济盈亏各是多少？
5. 为什么反复收权利金和展期，不能被当成固定利息或消除旧亏损？
6. 期初权益10,000，期间入金1,000、提款500，期末10,300，净损益是多少？这就是时间加权收益率吗？
7. 先涨20%再跌20%是否保本？净值跌50%后需涨多少才能回到原高点？
8. 交易App显示卖出成交，就能确认钱可以立即提现、资产由该品牌自己托管吗？

## 答案与解释

1. **不是。** 股票描述权益资产，ETF是投资载体，现货是交易/交割方式，期权是权利义务结构，券商是服务角色。ETF份额可以成为期权标的，但须核对该具体合约。
2. **不是。** 永续仍有资金费、保证金、标记价和强平等机制；1倍合约也不自动等于现货持有。不同产品规则不能统一概括。
3. **约亏50美元，相对初始保证金为50%。** 这不是亏损上限或强平价公式；强平还取决于维持保证金、标记价、账户方式及成本等。
4. **接股款10,000，整体亏1,800美元，未计费用。** `200-(100-80)×100=-1,800`；持有股票的浮亏也进入权益，不能只计200收入。
5. **每次收款对应新的风险义务。** 回补可能花更多钱；展期是旧仓平仓加新仓开仓，旧损益不消失，新现金流不能单独算总利润。
6. **净损益-200美元。** `10,300-10,000+500-1,000=-200`，这是金额对账，未处理现金流时点的收益率方法另查 [[section03-绩效评估]]。
7. **不保本。** `1.2×0.8-1=-4%`；50涨回100需涨100%。回撤计算还需剔除外部资金进出的影响。
8. **不能。** 成交、交收、可用和可提现不同；券商、执行场所、清算和托管主体应分别看协议与对账记录。

完成后任选一个实际看到的产品，仅做纸面识别卡：资产/结构/主体 → 数量单位 → 权利义务 → 资金占用 → 费用和压力损失 → 退出/结算。不能确认的内容写“未知”。
