# 资金、杠杆与交易成本：先算义务，再看余额

## 五个金额不能互相代替

| 名称 | 是什么 | 不能误认为 |
|---|---|---|
| 名义本金/名义敞口 | 按合约数量、乘数及价格等规格得到的参考金额 | 初始付款、最大损失，或所有产品可直接比较的实际风险 |
| 账户权益 | 账户资产按一致口径估值后减去负债；含持仓浮动损益 | 仅现金余额，或只累计已平仓利润 |
| 保证金 | 为融资或合约履约要求保留的资金/资产；初始与维持要求不同 | 期货购买标的的首付款，或任何情况下的亏损上限 |
| 权利金 | 期权权利的价格：买方支付、卖方收取 | 保证金、存款本金，或卖方收款当刻已经实现的全部利润 |
| 担保/抵押资金 | 覆盖潜在付款、交股或其他履约义务的现金/资产 | 可同时拿去做另一笔交易的自由现金；冻结不等于已发生损失 |

证券融资保证金与衍生品履约保证金的法律和资金机制不同，要读对应协议。CME说明期货保证金用于履约，而非购买标的；证券融资也可能损失超过初始投入。[CME保证金基础](https://www.cmegroup.com/education/courses/introduction-to-futures/margin-know-what-is-needed)、[SEC保证金说明](https://www.sec.gov/investor/pubs/margin.htm)

## 100美元保证金控制500美元敞口

假设一个损益近似线性的多头合约，以100美元初始保证金承担500美元名义敞口，相当于按初始保证金口径计算的5倍杠杆。

```text
标的反向变动10% → 合约毛损益约 -500×10% = -50美元
相对初始100保证金 → 约亏50%
```

这只是忽略费用、资金费及非线性因素的算术，**不是100美元的保证亏损上限，也不是跌20%才会强平的规则**。实际维持保证金、标记价、追加资金、全仓/逐仓方式和强平成本可能使持仓更早被处置；跳空与流动性也会影响损失。空头在标的上涨时受损，反向或非线性产品必须换用自己的公式。

杠杆比较还要说明分母：500名义/100初始保证金是5倍，不表示一个另有10,000权益的整个账户也有5倍暴露。名义相同的现货、期货与期权，价格敏感度、跳空和到期义务不同；期权还需看Delta/Gamma/IV等，不能只比名义本金。参见 [[part15-crypto/chapter03-derivatives/合约机制、保证金与盈亏结算#杠杆、名义敞口与初始保证金|杠杆、名义敞口与初始保证金]]、[[section02-binance-small-capital]]。

## 买期权的小门票与卖期权的担保

标准股票期权通常报价乘100股，1张报价1美元通常先付100美元，而非先买100股股票；买方在无额外借款、未行权转为股票时，期权本身的损失通常限于权利金加费用。深虚值/短期期权也可能全部归零。

卖方收取权利金，同时承担义务：现金担保Put需要足额接股款，备兑Call需要可交付股票；收到200美元不代表只承担200美元风险。被指派后还会形成股票头寸与后续风险，见 [[section04-binance-expiry-collateral|行权与充分担保实例]]。平台抵押币种、冻结和释放规则在那里独立核对，本页不把某一家规则当成通用标准。

## 流动性、价差与费用

流动性是能否在所需数量和时间内，以可接受价格成交；高历史成交量不保证当前有足够深度。Bid是买方愿付价，Ask是卖方要价；买入通常面对Ask、卖出面对Bid。

例如即时Bid=99、Ask=101，买1单位实际成交101后立即以99卖出，在没有市场变化的理想简化例中已亏2，尚未计费用。中间价100和Last都不保证能成交；限价单控制价格条件，但可能不成交或只成交部分。

成本可能包括佣金/交易及监管费用、买卖价差、滑点、融资利息、借券费、资金费、基金持续费用、换汇及交割/转账费用。适用税费依身份与法域另核；不在基础文档中预设税率。先统一币种和时间段，再算费用后的结果。

## 成交、清算、交收与可用不是同一时点

成交确认表示价格与数量达成；清算确定应付应收义务；交收完成证券/资金转移。可交易、可提现、已结算和未被冻结的余额可能不同。应分别检查交收日、货币、节假日、托管、对手方及抵押释放，不能把“已卖出”立即理解为“所有资金都能提走”。

公司行动、停牌、违约、跨市场时差、系统故障或交付物不匹配还可能带来结算和操作风险。具体周期和强平规则具有市场差异，按产品当前条款核对，不在这里统一写成T+0或T+1。

## 一张纸上的最小核查

写出：实际权利/义务 → 数量及单位 → 名义与权益分母 → 压力损失 → 现金/股票抵押 → 可执行价格和总成本 → 到期/结算 → 退出未成功时的风险。任意关键项未知，就先保留未知，不用钱包余额或低报价代替答案。
