# 现金流与总收益：收到钱不等于赚到钱

## 先区分收款、利润与权益

现金流描述钱进出，收益描述持有资产/承担义务后的经济结果。入金、借款、卖出资产收回本金、收到股息或期权权利金，都可能增加现金，但经济含义不同。

- 买资产支出现金，同时取得资产，不能把全额支出立刻记作亏损。
- 卖资产收款包含原本金，不能全算盈利。
- 卖开期权收到权利金，同时产生期权负债；应将负债估值纳入权益。
- 未卖出的股票或未平的期权也有浮动损益，不能只看已实现部分。

对全额付款、无外部追加资金的一项简单持仓，若期末价值不含已另行领取的分配，可以写：

```text
期间总收益率 = (期末持仓价值 - 初始投入 + 另行领取的分配 - 适用成本) / 初始投入
```

例如投入100，期末持仓值90，期间另收到5分配，忽略费用后总收益为-5%，不是“收了5%所以赚5%”。若期末账户权益已经包含该5现金，就不能再加一次分配。总收益应同时看价格变化、收入和成本。[FINRA：Evaluating Performance](https://www.finra.org/investors/investing/investing-basics/evaluating-performance)

## 现金担保Put：收200也可能整体亏1,800

假设卖1张标准100股Put，`K=100`，总权利金200美元（每股2美元）；准备按合约接股，持有到期，标的跌至80并被指派。忽略费用、税、融资、汇兑和时间价值：

```text
被指派付款 = 100×100 = 10,000美元
取得股票市值 = 80×100 = 8,000美元
整体经济盈亏 = 200 - (100-80)×100 = -1,800美元
扣权利金后的经济成本 = 10,000-200 = 9,800美元
```

接股后的1,800损失即使尚未卖股，也应体现在权益中。9,800是经济成本，不代表所有平台允许抵押只准备9,800；具体资金要求独立核对。股票若继续跌，后续损失继续变化。[OIC：Cash-Secured Put](https://www.optionseducation.org/strategies/all-strategies/cash-secured-put)

备兑Call则是持有股票并卖Call：权利金提供有限缓冲，但让渡部分上涨空间，股票下跌仍会亏损。[OIC：Covered Call](https://www.optionseducation.org/strategies/all-strategies/covered-call-buy-write)

### 为什么反复收权利金不是固定利息

每次卖出都重新承担股票价格、波动率、期限、流动性和指派风险；可收到多少权利金、抵押多少资金和股票最终值多少，都不固定。高收款频率不等于稳定总收益，也不能把一次月度权利金直接年化成可持续收益率。

**展期是平旧仓、开新仓，旧损益仍存在。** 例如原先卖开每股收2，随后以3买平，100股合约已亏100；再卖新合约收2.5，收到250现金，同时产生新义务。不能把新收的250当作抹掉旧亏损的利润。期货展期同样要区分旧、新合约。[CME：到期与展期](https://www.cmegroup.com/education/courses/introduction-to-futures/understanding-futures-expiration-contract-roll)

## 账户绩效：用完整权益与外部资金流对账

```text
期间净损益金额 = 期末权益 - 期初权益 + 外部提款 - 外部入金
```

权益包括现金、资产/持仓市值以及应计损益，扣除期权义务、融资及其他负债，并按一致估值与币种处理费用。冻结抵押仍属于相应资产，不能又当费用重复扣减；可用余额也不能代替完整权益。

例如期初10,000，期间入金1,000、提款500，期末10,300，净损益为 `10,300-10,000+500-1,000=-200`。即使期间累计收了600权利金，也不能据此说赚了600；其他持仓亏损、回补及费用须一起计算。

这是**金额对账式，不是已处理资金时点的收益率公式**。存在中途资金进出时，不能直接除以期初权益就宣称精确投资回报；时间加权收益与资金加权收益回答不同问题，完整方法复用 [[section03-绩效评估|绩效评估]]。

## 复利与回撤：看路径，不只看平均数

复利是收益留在本金中后继续参与后续收益计算。在假设每年固定10%、全部再投入且忽略费用税费的教学例中，1,000两年变成 `1,000×1.1²=1,210`；该假设不是收益承诺。[Investor.gov：Compound Interest](https://www.investor.gov/introduction-investing/investing-basics/glossary/compound-interest)

实际期间回报应连乘：`累计收益率=∏(1+r_t)-1`。先涨20%再跌20%，1,000变成960，累计亏4%，并未因算术平均为0而保本。

回撤比较当前净值与此前最高净值。净值100跌到50，回撤50%；从50回到100需要上涨100%，不是50%。下跌d后恢复所需涨幅为 `d/(1-d)`（0≤d<1）。有外部资金进出时使用调整后的单位净值，完整定义及例子复用 [[section03-最大回撤|最大回撤]]；历史回撤不保证未来损失上限。

## 一个通用练习：同标的比较不同结构

对同一假想标的、相同观察期限与一致资金口径，分别列“直接持有、保护Put、备兑Call、现金担保Put”的上涨/横盘/下跌结果，纳入权利金、现金或股票担保、费用、未实现损益、指派及机会成本。四种结构的现金占用和义务不同，**不能只比谁收的权利金多**。

先用 [[section08-strategy-payoffs|策略盈亏对照]] 和 [[section04-binance-expiry-collateral|交割及担保例子]]复算，再讨论是否有必要学习价差及短腿指派风险。期权是一类可系统学习的工具，不是学习进度或收益更高的自动结论。
