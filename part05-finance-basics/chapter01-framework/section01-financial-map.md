# 金融分类地图：资产、产品结构与交易组织

## 三个维度同时问

| 维度 | 问题 | 例子 |
|---|---|---|
| 资产/风险来源 | 最终暴露于什么价格、信用或现金流？ | 股票、债券、商品、外汇、加密资产 |
| 产品载体与结构 | 持有什么法律权利，承担什么付款或交割义务？ | 直接持有、基金/ETF、远期、期货、永续、期权、互换、CFD |
| 交易与服务组织 | 谁报价成交，谁执行、清算与保管？ | 交易场所、券商、交易对手、清算机构、托管机构 |

例如“股票ETF的Call”同时涉及股票风险、基金份额这一载体、期权权利这一结构，以及券商/交易场所/清算托管。**ETF可以作为期权标的**；ETF期权也不自动等于现金结算的指数期权，具体乘数、交付物和行权条款要另查 [[section01-binance-stock-options|股票期权规则]]。

## 资产类别：先认识经济含义

| 类别或常见入口 | 入门理解 | 需要注意 |
|---|---|---|
| 股票 | 对公司的股权权益，分享经营结果与剩余价值 | 股价波动、稀释、经营失败；分红并非保证 |
| 债券 | 对发行人的债权，按合同约定支付利息/本金 | 信用违约、利率、期限和币种风险；高票息不是安全保证 |
| 基金 / ETF | 集合资金的投资载体，可以持有股票、债券等多种资产 | 应穿透看持仓、策略和费用；“ETF”本身不能唯一代表资产类别，也不保证分散 |
| 商品 | 黄金、原油、农产品等实物及相关价格风险 | 实物存储、期限和供需；买金条、黄金ETF、黄金期货的权利与成本不同 |
| 外汇 | 不同货币间的兑换与相对价格，如EUR/USD | 买卖涉及一对货币；报价方向、汇率和融资成本需明确 |
| 加密货币 / 代币 | 依具体协议和条款形成的数字资产或相关权益 | 权利、储备与赎回安排差异大；价格、托管、协议与稳定币风险不能忽略 |
| 现金及现金管理工具 | 支付与流动性安排 | 币种、通胀、信用和结算限制；货币基金不等于所有银行现金 |

基金/ETF经常与股票、债券并列出现在投资菜单，但更精确地说它是一种载体。Investor.gov对ETF的说明强调其集合资金并投资于不同资产；其美国注册类别说明不直接替代其他市场的法律分类。[Investor.gov：ETF](https://www.investor.gov/introduction-investing/investing-basics/investment-products/mutual-funds-and-exchange-traded-2)

## 现货与衍生品：取得权利的方式不同

**现货不是与所有资产类别互斥的严格类别。** 它通常描述按现行价格买卖并依惯例近期交割的市场/交易方式：可以有黄金现货、外汇即期、加密资产现货，也可以直接买股票或债券。现货不意味着所有市场都实时交割、自托管或无风险。

| 结构 | 基本机制 | 额外核查点 |
|---|---|---|
| 直接持有 | 持有资产、证券权益或对托管人的相关请求权 | 实际所有权/受益权、托管、分红/利息和交割；有借贷时仍会有杠杆 |
| 远期 Forward | 双方约定未来按指定条款买卖或现金结算，常见于场外定制 | 对手方、抵押、期限与提前终止；不默认每日同样结算 |
| 到期期货 Futures | 标准化合约，通常在交易所交易并集中清算，具有到期安排 | 保证金、逐日盯市、最后交易、实物/现金交割及展期 |
| 永续 Perpetual | 无固定到期，常通过资金费等机制约束与参考价的偏离 | 资金费、标记价、维持保证金、强平和下架；不保证价格始终等于现货 |
| 期权 Option | 买方付权利金取得按约定条件买/卖的权利；卖方承担被行权时的义务 | Call/Put、K、期限、乘数、美式/欧式、实物/现金交割 |
| 互换 Swap | 双方按公式交换一段时期的现金流，如固定/浮动利率 | 名义本金、支付频率、利率/汇率及对手方；并非所有互换都交换本金，清算方式依产品而定 |
| 差价合约 CFD | 与提供方约定按标的价格变化结算差额，通常不持有标的本身 | 对手方、杠杆、隔夜融资、价差与适用限制；不是股票所有权 |

永续与到期期货都可能使用保证金，主要区别之一是**是否有固定到期和对应交割安排**；资金费、结算和市场组织仍需逐合约核对。到期期货展期要结束旧合约并进入新合约，可能有基差及成本；永续无固定到期不等于没有持仓成本。

结构参考：[CME：期货与远期](https://www.cmegroup.com/education/courses/introduction-to-futures/futures-contracts-compared-to-forwards)、[CFTC术语表（含互换）](https://www.cftc.gov/LearnAndProtect/AdvisoriesAndArticles/CFTCGlossary/index.htm)、[ASIC MoneySmart：CFD](https://moneysmart.gov.au/complex-investment-products/contracts-for-difference-cfds)。此处采用经济机制说明，不把单一法域的监管分类推广到所有地区；集中清算也不能完全消除风险。

币安股票/商品/加密期权与TradFi永续已分别说明，直接复用 [[section06-binance-other-derivatives|不同币安衍生品]]。TradFi永续休市参考价和标记价机制依产品而异，不能说全部冻结，也不能概括全部以USDT结算；平台规则见该文及更新2026-09-23的 [官方FAQ](https://www.binance.com/en/support/faq/detail/fe7dcdf24f1943d98b368f5f9f744398)。本页核验日2026-10-16。

## 谁负责成交、清算和托管

| 角色 | 主要职责 | 不应据此推定 |
|---|---|---|
| 交易所/交易场所 | 提供交易规则、报价/撮合和市场管理；具体职责依市场制度 | 它就是你的券商、托管人，或保证任何报价都可成交 |
| 券商/经纪商 | 提供客户账户与市场接入、接收/执行/路由订单，按协议提供服务 | App里显示资产就等于该App同时承担全部清算托管职责 |
| 清算机构/中央对手方 | 清算交易义务、管理抵押与违约风险；集中清算中可介入买卖双方之间 | 所有场外交易都集中清算，或清算完全消除风险 |
| 托管机构/证券存管体系 | 依协议保管/登记资产、维护记录并支持交收及公司行动 | 保管意味着保本，或不再需要对账和查法律权利 |

一笔交易可简化理解为“投资者委托→券商接入/执行→交易场所成交→清算与资金证券交收→托管记录”。这只是常见证券/交易所衍生品的示意；同一机构可能兼多种角色，场外双边交易和自托管加密资产的链条不同。

职责参考：[SEC Investor.gov：Market Participants](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/market-participants)。该页用于理解美国证券市场中的分工，其他市场应按当地制度和合同核对。

交易场所、券商、清算与托管应查各自正式名称与协议，不只认品牌。上一轮的 [[section01-binance-stock-options|Nest Trading / Alpaca服务链]]就是具体例子；概念正确不代表已确认个人账户的资产保护安排。
