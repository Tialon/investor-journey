# 波特五力模型

## 把行业判断转为可核验的问题

| 力量 | 观察证据 |
|---|---|
| 现有竞争 | 份额、价格、利润率、扩产和销售费用变化 |
| 新进入者 | 资本/许可/技术门槛，新供应商的真实交付 |
| 替代品 | 总拥有成本、客户迁移、替代方案性能 |
| 客户议价 | 客户集中度、议价/招标、流失和账期 |
| 供应商议价 | 关键投入占比、集中度、替代成本 |

不要给五项机械评分后直接买股票。最终检查这些力量如何影响单位售价、销量、毛利、再投资和现金流。结论至少附一项一手证据及可能推翻它的信号；缺数据时记录未知。
