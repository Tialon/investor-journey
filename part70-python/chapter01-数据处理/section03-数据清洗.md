# 数据清洗

## 先定义数据契约

每条数据保留资产唯一标识、时间/时区、数值、币种、单位、来源、获取时间、是否复权及原始记录。检查重复、缺失、类型、异常、公司行动和报价新鲜度，再用于估值或收益计算。

空值不自动填0，停牌/休市不等于无价格风险。分红拆股前后要统一收益口径；金融数值的正负号与单位不能依赖列名猜测。对异常保留原始值与清洗原因，不直接删除所有极端损失。

使用小样本人工核对后再批量运行。记录输入/输出行数、去重数量和无法解释的差异；先做离线数据检查，本页不提供可直接实盘下单程序。
