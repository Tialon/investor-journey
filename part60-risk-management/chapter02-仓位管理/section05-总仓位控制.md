# 总仓位控制

## 一张账户风险表

| 项目 | 记录口径 |
|---|---|
| 净值与现金 | 时间戳、基准币种、已结算/未结算、是否有用途限制 |
| 总市值/净敞口 | 多头与空头分别列，再列净额；净额小不代表风险小 |
| 集中度 | 单公司、行业、同事件、同到期 |
| 期权义务 | 最大损失、接股/交股、指派后暴露 |
| 保证金 | 当前与联合压力下占用，不等于损失 |
| 流动性 | 紧急用款储备、执行成本、报价异常 |

预先写下停止新增风险、减仓及重新评估的条件。资金入金不应掩盖旧亏损，不能把可用购买力直接当可承受风险。交易权限、当前持仓或价格缺失时，先核对账户再新增风险。
