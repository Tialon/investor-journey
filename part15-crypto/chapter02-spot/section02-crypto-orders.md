# 订单类型、盘口与成交约束

## 订单决定执行方式，不保证结果

| 类型 | 用途 | 主要限制 |
|---|---|---|
| 市价 | 优先成交 | 价格和滑点不保证，深度不足可有异常结果 |
| 限价 | 约束可接受价格 | 可部分成交或一直不成交 |
| Post-only | 尽量只提供流动性 | 遇立即成交条件可能拒绝/取消，按平台规则 |
| IOC/FOK | 限定成交数量与等待语义 | 具体行为及支持类型需核对 |
| 止损市价/限价 | 条件触发后下单 | 触发≠成交；市价滑点、限价无法成交 |

限价单若立即跨过盘口，仍可能是taker；maker/taker由实际撮合角色决定，不由“限价”名称决定。

## 精度与最小金额

下单前读取当前价格tick、数量step、最小/最大数量、名义金额与适用市价规则。用十进制算术按规则向可接受方向调整，并重新算金额、现金和风险；不能仅按界面小数位四舍五入。

买卖盘口、数量、时间和订单规模一起看。Last不是一定可成交的价格，高成交量不证明你能低成本退出。请求受理、订单状态、累计成交和成交明细分别留痕。
