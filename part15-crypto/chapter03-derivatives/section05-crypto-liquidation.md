# 指数价、标记价与强平机制

## 三种价格

成交价是撮合的实际价格；指数价按产品规则聚合参考市场；标记价是平台计算的风险参考。未实现收益、强平判断和止损触发可能使用不同价格，必须分别确认。

当保证金权益不满足维护要求时，可触发减仓或强制处置。维护比例可能分档，费用、资金费、其他仓位和抵押折扣会改变条件。强平价、破产价和最终成交价不是同义词。

## 仅用于理解的简化公式

孤立的线性单仓：正数数量Q、入场E、保证金I、固定维护率m，维护要求=m×Q×P。忽略全部费用、资金费、层级扣减和其他资产，权益等于维护要求时：

```text
多头参考P = (E − I/Q) / (1 − m)
空头参考P = (E + I/Q) / (1 + m)
```

E=50,000、Q=0.02、I=100、m=0.5%，多头参考约45,226.13，空头约54,726.37。这是教学等式，不能代替交易所清算引擎或真实强平价。

## 退出控制

保护退出应在正常预期情况下先于强平发生，并留下价格来源差异和跳空/滑点缓冲。触发价未到不代表标记价未到强平条件；止损也不保证成交。维护档位、标记或账户证据缺失时，不把未知清算安全性当正常。
