# 现货与合约交易检查清单

## 交易前

- [ ] 明确市场、账户、币种、交易对/合约规格、数量单位和权限。
- [ ] 核对行情完整/新鲜、账户和挂单事实、费用、过滤器及计价来源。
- [ ] 记录方向或配置假设、失效条件、数量、单笔和账户风险、未完成订单占用。
- [ ] 合约另查保证金模式、持仓模式、维护档位、标记价、资金费结算与保护单。
- [ ] 验证价格跳变、流动性下降、稳定币/抵押资产冲击与网络故障下的计划。

## 交易中与恢复

- [ ] 受理、成交、部分成交分别记录；下单超时先查询，未确定前不重复提交。
- [ ] 仓位按真实成交更新，保护单和资金预约随之检查。
- [ ] 减仓核对方向和剩余仓位，不把SELL自动当平多。
- [ ] 重启后恢复账户、订单、成交、费用与资金费；完整性未知不填零。
- [ ] 暂停新开仓与处理保护单分别管理，不追发过期信号。

## 交易后

使用 [[虚拟币交易复盘模板]]：保存实际成交、扣费币、结算资金费、已实现/未实现、借款与外部资金流、账户差异，以及规则偏离。

模拟和真实记录分开。把“有信号”“通过风控”“被允许提交”“提交状态已知”“已成交”“已对账”作为不同阶段验收。

本清单不预设账户配置或授权，不因学习完成自动开启任何真实交易。
