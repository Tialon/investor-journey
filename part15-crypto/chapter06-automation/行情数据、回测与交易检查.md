## 行情窗口、K线闭合与数据新鲜度

### 三类时间不能混用

记录交易所事件时间、系统收到时间和本地处理时间；另记K线起止/是否闭合。信号用的是已闭合数据还是当前报价，要明确，不能把未来收盘值用于历史入场。

统一时区/交易日边界，保留原始时间戳。现货、永续、指数与标记价格是不同数据流，即使代码类似也要带market identity与价格类型。

### 断线补数与窗口验收

检查重复、乱序、缺口、窗口数量、覆盖起止和新鲜度。重连后从最后已确认边界补数并去重；交易所历史接口分页、上限与历史深度不足时保留缺口，不能只因K线数量凑齐就证明连续。

缺失不能填零或向后填未来值。一个活跃报价不证明整个窗口完整，WebSocket连接正常不证明数据新鲜。依赖完整窗口的策略应等待恢复，展示可以保留注明时间的旧快照。

新鲜度阈值依据频率与任务，有界容忍网络抖动不意味着接受过期账户或订单事实。人工抽查断线、日界线与窗口重算。

### 指标计算的额外验收

保留输入市场/价格流、时间框架、完整K线边界、历史缺口、算法（SMA/EMA/RMA）、初始化、预热、零分母及缺值策略。EMA、RSI、MACD和ATR可能因短历史或平滑实现不同而不一致；跨平台比较先对齐口径。

高周期值只在当时闭合后供低周期使用，背离/摆动点按实际确认时间记录。盘中指标仅能在明确的盘中规则中使用，不能与事后收盘信号混写回测。

计算小例与应用见 [[part15-crypto/chapter07-indicators/常用技术指标：均线、RSI、MACD、ATR与成交量#均线：趋势过滤、回调与跟踪退出|均线：趋势过滤、回调与跟踪退出]]、[[part15-crypto/chapter07-indicators/常用技术指标：均线、RSI、MACD、ATR与成交量#RSI：动量状态、回归确认与钝化|RSI：动量状态、回归确认与钝化]]、[[part15-crypto/chapter07-indicators/常用技术指标：均线、RSI、MACD、ATR与成交量#MACD：趋势动量、柱体与交叉边界|MACD：趋势动量、柱体与交叉边界]]、[[part15-crypto/chapter07-indicators/常用技术指标：均线、RSI、MACD、ATR与成交量#ATR：波动距离、仓位与保护退出|ATR：波动距离、仓位与保护退出]] 和 [[part15-crypto/chapter07-indicators/常用技术指标：均线、RSI、MACD、ATR与成交量#成交量：量价、相对量与执行确认|成交量：量价、相对量与执行确认]]。

### 跨周期数据连接

日线/4小时/小时/15分钟要按各自实际边界、闭合与收到时间连接。整点多源未同时到达、低周期缺根、高周期未更新和未收盘重绘分别记录。

最近高周期完整值在正常周期内可继续引用，但下一应闭合版本缺失不能永久忽略；准确时序和UTC/北京时间例子见 [[part15-crypto/chapter08-multi-timeframe/多周期分析：时间对齐、入场与仓位保护#多周期K线闭合、时间对齐与信号有效期|多周期K线闭合、时间对齐与信号有效期]]。

### 与支撑压力及K线配合

价格形态须满足 L≤min(O,C)≤max(O,C)≤H；同源完整小K聚合的大K使用首O、最高H、最低L、末C与求和V。检查缺根、重复、时区和价格/数量单位，示例见 [[part15-crypto/chapter09-price-action/价格行为实战：多空案例与失败复盘#区域、K线与量价的完整多空交易案例|区域、K线与量价的完整多空交易案例]]。峰谷的确认时间必须晚于所需右侧数据；同根触及止盈止损时，OHLC不能推出先后，见 [[part15-crypto/chapter09-price-action/价格行为实战：多空案例与失败复盘#影线、放量、假反转与假突破的失败案例|影线、放量、假反转与假突破的失败案例]]。

## 成本后回测、回放与验证层级

### 数据与执行模型

历史回测保留当时交易对、下架/新上市、精度、最小金额、手续费、借币、资金费、标记/指数价格与可用深度。仅用OHLC无法知道一根K内先触发止损还是止盈，更不能证明真实强平成交价。

禁止把未收盘K、未来事件、今天的费率或交易规则当历史已知。模拟限价成交需给排队/部分成交假设；低流动性市场按中间价全部成交会高估收益。

### 验证层级

公式单元检查→历史数据回放→故障和边界场景→样本外成本测试→模拟账户流程→另行评估真实执行。模拟与测试网流动性、费率和权限可能不同，不能把接口跑通当盈利或生产认证。

合约回测需事件顺序：价格/标记、成交、资金费、维护档位变化和保护单。现货正收益证据不能改标签当合约验证。

报告净收益、未实现、回撤/恢复、成本、最差交易、换手、资金占用、缺数据和模型限制，保留失败区间。不用权利金/网格收益/资金费收入代替账户净收益。

## 现货与合约交易检查清单

### 交易前

- [ ] 明确市场、账户、币种、交易对/合约规格、数量单位和权限。
- [ ] 核对行情完整/新鲜、账户和挂单事实、费用、过滤器及计价来源。
- [ ] 记录方向或配置假设、失效条件、数量、单笔和账户风险、未完成订单占用。
- [ ] 合约另查保证金模式、持仓模式、维护档位、标记价、资金费结算与保护单。
- [ ] 验证价格跳变、流动性下降、稳定币/抵押资产冲击与网络故障下的计划。

### 交易中与恢复

- [ ] 受理、成交、部分成交分别记录；下单超时先查询，未确定前不重复提交。
- [ ] 仓位按真实成交更新，保护单和资金预约随之检查。
- [ ] 减仓核对方向和剩余仓位，不把SELL自动当平多。
- [ ] 重启后恢复账户、订单、成交、费用与资金费；完整性未知不填零。
- [ ] 暂停新开仓与处理保护单分别管理，不追发过期信号。

### 交易后

使用 [[虚拟币交易复盘模板]]：保存实际成交、扣费币、结算资金费、已实现/未实现、借款与外部资金流、账户差异，以及规则偏离。

模拟和真实记录分开。把“有信号”“通过风控”“被允许提交”“提交状态已知”“已成交”“已对账”作为不同阶段验收。

本清单不预设账户配置或授权，不因学习完成自动开启任何真实交易。
