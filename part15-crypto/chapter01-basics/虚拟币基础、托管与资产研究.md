## 虚拟币资产、现货与合约

### 先区分买的是什么

| 产品      | 持有什么          | 主要额外风险         |
| ------- | ------------- | -------------- |
| 无借贷现货   | 币或对托管平台的余额请求权 | 价格、托管、流动性、下架   |
| 现货杠杆    | 币/现金与借款义务     | 利息、抵押率、强制处置    |
| 永续合约    | 多空价格敞口，通常无到期日 | 资金费、保证金、强平、ADL |
| 到期合约    | 特定到期/交割规则下的敞口 | 基差、到期、结算与展期    |
| 链上借贷/质押 | 协议、验证者或平台对应权益 | 合约、预言机、锁定、罚没等  |

交易对BASE/QUOTE表示用报价资产计价基础资产，例如BTC/USDT。USDT计价收益不等于法币或人民币收益，还受稳定币与汇率变化影响。

现货SELL通常减少已有资产，不等于建立空头；合约BUY可能开多，也可能平空。市场、账户、币种、合约方向必须一起识别，不能只靠交易代码。

### 知识使用边界

连续交易不代表所有时刻都有足够流动性；维护、暂停充提和下架也会中断交易。任何平台规则、费率、资金费时刻和权限都需按具体产品复核，不把示例固化为生产默认。

先检查所在地与账户实体的资格、产品限制和税务记录要求。不因平台可以注册就推定当地可合法使用全部产品。保留成交、划转、充值提现、费用与计价来源，本模块不预设居民身份或税率。

## 交易所托管、钱包与密钥安全

### 资产控制权与余额不同

交易所内余额由平台系统记录，提款还依赖平台兑付、权限及运行状态。自托管钱包由私钥授权，助记词通常是恢复整个钱包的关键材料；丢失或泄漏可能无法挽回。

热钱包方便连接应用，硬件钱包减少密钥直接暴露，但仍须核对签名对象、地址与授权。多签需要阈值、签名人独立性及恢复流程，不能仅凭名称判断安全。

### 最小安全流程

使用独立密码和适当的多因素认证，保存官方入口，核对提款地址与账户活动。助记词、私钥和API密钥不进入笔记库、Git、日志或AI提示词；恢复材料离线保管并验证可恢复性，不在陌生网页输入。

API先用最小权限，观察程序使用只读；交易权限与提款权限分开，按支持情况设置来源/IP限制。所谓官方客服、空投或补偿若索要助记词，应停止交互。

托管分散可降低单平台集中度，也增加操作和对账复杂度。保留资产位置、用途与负责人，不把链上自托管称为无风险。

## 充值提现、网络与链上授权

### 转账先核对五项

资产与代币合约地址、发送链/接收链、接收地址、是否需要memo/tag、收款方是否支持该资产与网络。代码相同不代表同一代币，同格式地址也不代表网络相同。

核对最小充提金额、手续费、确认数和维护状态。首次新地址先用符合最低限额的小额验证并确认到账；小额成功也不能替代大额时重新核对地址。不要只检查地址首尾，防范剪贴板替换与地址污染。

### 状态需要分层

平台已受理→已广播/交易哈希→链上确认→接收平台入账。平台请求ID与链上哈希分别记录；确认数不足不等于失败，余额未更新也不能盲目重复转账。

代币转账可能需要原生币支付gas。跨链桥是另一项协议/资产封装风险，不只是选择便宜网络。链上授权、签名许可与普通转账不同；核对spender、限额、到期及授权资产，撤销授权也可能需要交易和gas。

误转、暂停或疑似欺诈时保留交易哈希与证据，通过已验证官方渠道处理；不向陌生“恢复服务”交出密钥。

## 稳定币、抵押资产与收益产品

### 稳定不等于保证兑付

区分法币储备型、加密抵押型和算法机制，检查发行人/协议、储备构成、赎回资格、链与合约、冻结能力和退出流动性。1枚稳定币的交易价、目标锚定价和可实际兑付价值可能不同。

资金在稳定币中仍有发行人、平台、脱锚、合约和网络风险。两枚美元稳定币的直接交易对也可能有价差；不能假定兑换永远1:1。

### 作为保证金时的双重影响

保证金资产价格下降可能同时降低账户权益与抵押价值。多资产账户还可能应用抵押折扣；抵押率、可用余额和法币估值要分别记录。

借贷收益、平台理财与链上质押不是现金利息的同义词，需检查锁定期、赎回、资金用途、合约/验证者风险及奖励币价格。高APY可能来自短期补贴、代币通胀或风险承担，不自动等于可持续收益。

日常对账分别列资产数量、计价价格、可用性与用途；未知价格不填1或0。

## 代币研究、供给解锁与基本面

### 代币价格需要价值承接机制

调查用途、持有者权利、费用流向、发行/销毁、团队与投资者配置、解锁、治理、验证者/用户集中度及协议控制权。项目收入、协议费用和代币持有人收入是不同数据，不自动等于股票净利润。

```text
流通市值 = 价格 × 流通量
FDV = 价格 × 采用明确口径的完全稀释供给
```

流通定义和未来供给可能不同，核对来源、时间与解锁规则。小流通高FDV不证明必跌，但提示潜在供给压力；不能把FDV直接当可退出的市场价值。

### 一页研究卡

记录链/合约标识、公开资料日期、真实用户/收入、供给变化、持币与交易所集中度、退出深度、催化与失效条件。链上地址不等于独立用户，TVL可能受币价与重复抵押影响，交易量可能包含刷量。

区分官方承诺、可核查事实和个人推断。异常授权、管理员权限、漏洞、增发或流动性撤出需进入压力情景。AI可帮助提取，但不替代原文与链上核验。
