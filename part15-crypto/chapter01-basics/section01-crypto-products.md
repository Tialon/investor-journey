# 虚拟币资产、现货与合约

## 先区分买的是什么

| 产品 | 持有什么 | 主要额外风险 |
|---|---|---|
| 无借贷现货 | 币或对托管平台的余额请求权 | 价格、托管、流动性、下架 |
| 现货杠杆 | 币/现金与借款义务 | 利息、抵押率、强制处置 |
| 永续合约 | 多空价格敞口，通常无到期日 | 资金费、保证金、强平、ADL |
| 到期合约 | 特定到期/交割规则下的敞口 | 基差、到期、结算与展期 |
| 链上借贷/质押 | 协议、验证者或平台对应权益 | 合约、预言机、锁定、罚没等 |

交易对BASE/QUOTE表示用报价资产计价基础资产，例如BTC/USDT。USDT计价收益不等于法币或人民币收益，还受稳定币与汇率变化影响。

现货SELL通常减少已有资产，不等于建立空头；合约BUY可能开多，也可能平空。市场、账户、币种、合约方向必须一起识别，不能只靠交易代码。

## 知识使用边界

连续交易不代表所有时刻都有足够流动性；维护、暂停充提和下架也会中断交易。任何平台规则、费率、资金费时刻和权限都需按具体产品复核，不把示例固化为生产默认。

先检查所在地与账户实体的资格、产品限制和税务记录要求。不因平台可以注册就推定当地可合法使用全部产品。保留成交、划转、充值提现、费用与计价来源，本模块不预设居民身份或税率。
