# 均线：趋势过滤、回调与跟踪退出

## 计算口径

```text
SMA(n) = 最近n根完整K线的收盘价之和 / n
EMA_t = α×Close_t + (1−α)×EMA_(t−1)，常见α=2/(n+1)
```

均线价格输入、周期、初始化和预热长度必须固定。EMA可用首价或前n根SMA初始化，短历史下会得到不同结果；“有n根数据”不证明已消除EMA初始化影响。20小时与20日不是同一指标。

算术例：收盘100、102、101，SMA3=101；把它作为EMA3初值，下一收盘105、α=0.5，EMA3=103。此短例演示公式，不能称为EMA20趋势信号。

## 策略分工

- 趋势过滤：价格在快慢均线上方、快线高于慢线且斜率向上，可作为多头研究条件；空头镜像。要定义斜率比较窗口，不能凭图形感觉。
- 突破入场：均线确认背景，价格仍须突破已定义结构并用完整收盘/可成交报价验证。交叉本身不保证突破成功。
- 回调加仓：只在原趋势和支撑未失效、价格止跌确认且总风险允许时考虑；不是碰到EMA20就自动买入。
- 减仓/退出：结构失效或预设保护触发优先；收盘破均线可作时间/趋势复核。不能为等慢线死叉而撤掉硬保护。

## 接到现货突破案例

以下为手工设定的闭合指标快照，完整历史另未提供，不能声称由同一真实数据计算。

已收盘C=99.8、EMA20=98.5（前值98.2）、EMA50=97.0（前值96.9），前20根最高收盘99.5。背景向上且突破已知结构；若成交条件与其他规则满足，下一可成交报价买2币@100。

随后C=103.8、EMA20=101、EMA50=98，确认后才买1@104，组合保护按规则提至100。止盈与失败路径见 [[section05-crypto-spot-breakout]]，费用后利润为+22.369、假突破首笔退出为−8.392 USDT。

如果价格先跌到96，即使慢线尚未下拐也按保护处理，不等待“均线最终证明下跌”。均线下移造成价格重新在均线上方，也不证明仓位已盈利。

## 失效情形

横盘时反复交叉会累积费用；急剧反转时均线滞后；短期多头与高周期空头可能冲突。快慢均线和MACD都来自价格平滑，不是两份独立证据。未闭合K线、不同交易所/现货合约行情混用或不足预热会改变判断。

不设通用最佳周期。明确背景周期、执行周期与允许动作，先做成本后验证，详见 [[section06-crypto-indicator-workflow]]。
