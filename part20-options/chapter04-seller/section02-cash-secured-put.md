# 现金担保看跌期权（Cash-Secured Put）

> 以下价格均为虚构教学参数，不是当前行情。示例假设标准合约每张100股，未计费用、税、担保资金利息与汇兑；调整合约须核对实际乘数。权利金不是固定利息，现金担保只覆盖接股付款能力，不消除股票下跌风险。

## 1. 策略概述

现金担保看跌期权（Cash-Secured Put，简称 CSP）是另一个经典的卖方策略。它的核心思想：

> **卖出看跌期权 + 准备足够的现金买入股票 = Cash-Secured Put**

你卖出 1 张 AAPL 的看跌期权（Put），收取权利金。同时在账户中准备足够的现金（行权价 × 100），以备被行权时买入股票。

### 策略本质

CSP 的本质是**"愿意以某个价格买入股票，同时赚取等待的权利金"**。

换个角度理解：
- 你看好 AAPL，但觉得当前价格 $155 偏高
- 你愿意在 $145 买入
- 你卖出 $145 行权价的 Put，收取 $3 权利金
- 若被指派，须以 $145 买入；扣权利金后的经济成本为 $145 - $3 = $142，股价仍可能跌得更低。美式期权可能提前指派，并非触及价格就必定成交。
- 若到期未被指派且期权失效，保留每股 $3 权利金；这补偿期间承担的风险与资金占用，不是无风险收入。

## 2. 建仓要素

| 要素 | 说明 |
|------|------|
| 卖出 Put | 选择行权价和到期日 |
| 准备现金 | 行权价 × 100 × 合约数 |
| 收取权利金 | 卖出时立即收到 |

### 行权价选择

| 行权价 | 权利金 | 指派倾向（仅定性） | 思路 |
|--------|-------|----------|------|
| 深度 OTM（远低于现价） | 很少 | 很低 | 权利金较少，仍承担下跌和指派风险 |
| OTM（低于现价） | 较少 | 较低 | 主要赚权利金，附带低价买入机会 |
| ATM（接近现价） | 中等 | 不能只凭平值判断 | 平衡权利金和买入意愿 |
| ITM（高于现价） | 较多 | 较高 | 更倾向于被行权买入股票 |

**最常用**：卖出 OTM Put，行权价在你愿意买入股票的价格附近。

## 3. 盈亏分析

### 收益公式

定义：`p` 为每股权利金，`m` 为实际乘数，`n` 为张数，`P=p×m×n` 为总权利金。下面是到期经济盈亏，假设实值按合约交割并将所得股票按到期市价计价，不是平台保证的实际指派或到账结果。

$$\text{到期净盈亏}=[p-\max(K-S_T,0)]\times m\times n$$

- 到期股价 ≥ 行权价且未被指派时，净盈亏为总权利金 `P`。
- 到期股价 < 行权价且被指派时，净盈亏为 `P-(K-S_T)×m×n`。

即以行权价买入了市价更低的股票，权利金只能提供有限缓冲。

### 关键数据

| 指标 | 公式 |
|------|------|
| 最大盈利 | `P=p×m×n`，未计担保资金利息 |
| 盈亏平衡点 | `K-p`，每股口径 |
| 最大亏损 | `(K-p)×m×n`，股价跌到0，未计费用 |

### ASCII 盈亏图

```
净盈亏
  ^
+P|                 _____________  最大盈利封顶
  |               /
 0|-------------/--------------------> 到期股价 S_T
  |           /
  |         /
  +----------+-----+-----------------
            K-p    K
```

**与 Covered Call 的盈亏图对比**：相同标的、行权价与到期日并匹配资金假设时，两者的到期风险结构方向相同，都是下跌承受损失、上涨收益封顶，不是镜像。初始成本、利率/股息、费用和提前指派仍需分别核算。

## 4. 实例分析

### 场景设定

- 假设 AAPL 价格：$155
- 你卖出 1 张 AAPL Put，行权价 $145，30天后到期
- 收取权利金：$2.80/股 = $280/张
- 准备现金：$145 × 100 = $14,500

### 情景分析

| 到期股价 | 是否被指派（示例假设） | 整体经济盈亏 | 说明 |
|---------|---------|---------|------|
| $170 | 否 | +$280 | 期权失效，保留权利金 |
| $160 | 否 | +$280 | 期权失效，保留权利金 |
| $155 | 否 | +$280 | 期权失效，保留权利金 |
| $145 | 假设未被指派 | +$280 | 平值的实际指派结果另核，不由此表保证 |
| $142.20 | 是 | $0 | 盈亏平衡点（$145 - $2.80） |
| $140 | 是 | -$220 | 以$145买入市价$140的股票，净亏$220 |
| $130 | 是 | -$1,220 | 以$145买入市价$130的股票 |
| $120 | 是 | -$2,220 | 以$145买入市价$120的股票 |

**关键观察**：
- 被指派接股需支付 $14,500，扣权利金后的每股经济成本为 $142.20，不代表可将担保资金直接减至 $14,220；具体冻结/购买力依券商规则。
- 未被指派、期权失效时保留 $280；单期权利金/全额接股款为 $280/$14,500 ≈ 1.93%。若机械按12次相同结果简单年化，约为23.17%，仅为算术外推，既非预期也非保证收益；本例30天不能直接等同每月都可重复。
- 股价跌到0时，本例整体损失可达 $14,500-$280=$14,220，未计费用；收益评价还需纳入浮亏、回补和资金占用，不能只累计权利金。

## 5. Greeks 分析

| Greeks | 值 | 说明 |
|--------|---|------|
| Delta | 正（Short Put；Long Put的Delta为负） | 其他输入不变时，标的上涨通常有利于卖方持仓 |
| Gamma | 负 | Delta变化对卖方不利 |
| Theta | 正 | 时间衰减对卖方有利 |
| Vega | 负 | 波动率下降对卖方有利 |

Long Put的模型Delta乘以负的卖方张数后，持仓Delta转为正；例如多头Delta=-0.30，卖1张、乘数100，等效股数为+30。Delta是局部敏感度，不是固定盈利或指派概率。

## 6. CSP vs Covered Call

| 维度 | CSP | Covered Call |
|------|-----|-------------|
| 前提 | 有现金，想买股票 | 有股票，想增强收益 |
| 收益结构 | 相同条款与资金假设下，到期暴露可对应 | 同方向、上涨封顶与下跌风险，非镜像 |
| 最大盈利 | 权利金 | 行权价差 + 权利金 |
| 资金占用 | 需要冻结现金 | 需要持有股票 |
| 成本口径 | 经济接股成本为K-p；税务口径依法域另核 | 需合并持股成本、权利金与交股结果；税务另核 |

### 等价性证明

在同标的、同行权价和同到期、无股息的欧式模型下，Put-Call Parity为（c、p分别为每股Call、Put价格）：
$$c - p = S - K \cdot e^{-rT}$$

持有到期可支付K的现金资产 + 卖出Put，对应于持有股票 + 卖出Call。美式提前行权、股息、利率、费用和实际资金占用会影响执行与比较，不能据此断言两种策略在所有路径上完全相同。

## 7. 适用场景

### ✅ 最适合

- **想买入某只股票但觉得当前价格偏高**：卖出 Put 等待价格回调，同时赚取权利金
- **看好市场但想低成本建仓**：用 CSP 代替直接买入
- **高波动率环境**：IV 高时权利金丰厚
- **长期投资者**：不急于买入，愿意等待

### ❌ 不适合

- **强烈看空**：如果股价大跌，你会以远高于市场的价格买入
- **资金不足**：必须有足够的现金覆盖行权义务
- **波动率很低**：权利金太少，资金利用效率低

## 8. CSP与低价限价买单的区别

两者都可能表达低价接股意愿，但**不是等价订单**：

- 你想在 $145 买入 AAPL → 挂 $145 的限价买单
- 或者：卖出 $145 Put，收取 $2.80 权利金

两种方式的区别：
- 限价单：只有符合价格、流动性和订单条件并成交时才买股，可能不成交；适用交易费用仍要计算。
- CSP：卖开成交收每股 $2.80，同时产生有期限的合约义务；若被指派就须以 $145 买入，即使市价更低。触价不等于已被指派，退出通常需买平且可能亏损，并非随时撤掉限价单即可。

## 9. 常见错误

### ❌ 错误一：在强烈看空时卖出 Put

如果你认为股价会大跌，不要卖出 Put。被行权买入后股价继续下跌的损失可能远超权利金。

### ❌ 错误二：卖出太多 Put

CSP 的风险是被行权后股价继续大跌。控制仓位，不要把所有资金都用于担保 Put。

### ❌ 错误三：选择太深虚值的 Put

多头Delta绝对值为0.05的Put（相应卖方Delta约为+0.05）权利金极少，资金利用效率极低。你的现金被冻结，回报率可能还不如货币基金。

### ❌ 错误四：忽视财报等事件

财报后股价可能大幅跳空。如果你卖出的 Put 在财报后变为深度实值，亏损可能很大。

### ❌ 错误五：被行权后恐慌卖出

如果你被行权以 $145 买入了 AAPL，而市价是 $140，不要恐慌卖出。如果你当初是看好 AAPL 的，$142.20（扣除权利金后）的成本可能正是你想要的买入价。

## 10. 高级技巧：Wheel Strategy

Wheel Strategy 是 CSP 和 Covered Call 的组合循环：

```
卖出 Put → 被行权 → 买入股票 → 卖出 Covered Call → 被行权 → 卖出股票 → 回到卖出 Put
```

### 流程

1. **第一阶段**：持续卖出 OTM Put，收取权利金
2. **如果被行权**：以行权价买入股票，进入第二阶段
3. **第二阶段**：对持有的股票卖出 Covered Call
4. **如果被行权**：股票被以行权价卖出，回到第一阶段

**现金流特点**：有机会多轮收取权利金，但每轮报价、权限和担保条件会变化，不保证持续收入或总收益。
**风险**：股票大跌时亏损可能远超权利金；回补、展期不消除旧亏损。参见 [[section02-cashflow-total-return|现金流与总收益]]。

## 11. IBKR 操作说明

### 下单步骤

1. 在 TWS 中搜索标的股票
2. 选择"交易期权"→"卖出"→"Put"
3. 选择行权价（你愿意买入的价格）和到期日
4. 核对全额接股款K×实际乘数×张数，以及账户现行保证金、冻结与费用要求
5. 使用 Limit Order 提交

### 保证金要求

- 足额接股现金是CSP的履约准备，并非无需满足保证金或可用资金要求；费用和担保资金可用性按账户现行规则核对。
- Portfolio Margin显示的购买力占用可能不同，但不会减小被指派时的全额付款义务；若未备齐全额现金，不能仅凭较低占用就称为足额现金担保。

## 12. 小结

| 要点 | 内容 |
|------|------|
| 策略构成 | 卖出 Put + 准备足够的现金 |
| 适用观点 | 温和看多 / 想低价买入 |
| 最大盈利 | 权利金 |
| 最大亏损 | (K-p)×实际乘数×张数，股价跌到0，未计费用 |
| 核心优势 | 赚取权利金 + 有机会低价买入 |
| 核心劣势 | 被行权后股价可能继续跌 |
| 与 Covered Call | 数学上近似等价 |

### 思考题

1. 你想买入 AAPL，当前价格 $155。你卖出 $145 Put 收取 $3 权利金。到期时 AAPL 跌到 $135，你的实际买入成本是多少？比直接在 $155 买入亏了多少？
2. 为什么同条件下CSP和Covered Call有相同方向的到期风险结构？利率/股息、资金占用和提前指派会如何影响比较？
3. Wheel Strategy 的核心逻辑是什么？它在什么市场环境下表现最好？

### 参考答案

1. **第1题**：**被指派后的每股净成本为 $142，到期按 $135 计价时每股浮亏 $7。** 计算为 `145−3=142`；一张按 100 股举例，支付行权款 $14,500，已收 $300，净投入 $14,200，股票市值 $13,500，亏损 $700。若直接按 $155 买入同样 100 股，到 $135 时亏损 $2,000，因此该情景下 CSP 少亏 $1,300；不是没有亏损。忽略费用、利息与股息，且比较的是同一终点、同一股数。股价大涨时，CSP 也可能只赚权利金而错过持股上涨。

2. **第2题**：**两者在匹配资金条件后，均具有“下跌承担股票风险、上涨收益封顶”的到期形状。** 每股到期资产价值有恒等式 `S_T−max(S_T−K,0)=K−max(K−S_T,0)=min(S_T,K)`：左侧是持股加卖 Call，右侧是到期有 K 现金加卖 Put。比较必须采用同一标的、行权价、到期日和对应数量，并计入初始净投入；不能只比两笔权利金。无股息欧式合约可用 Put-Call Parity 加贴现资金精确联系，股息、利息和融资成本需调整。美式提前指派、交割时点、税费及券商资金占用规则会造成实际差别；两者都不是保本策略。

3. **第3题**：**Wheel 是先用现金担保卖 Put，若接股再卖等量备兑 Call，交割后再循环。** 它把愿意买入和愿意卖出的价格写进合约，持续收取权利金，同时承担持股风险和上涨被封顶的代价。较温和的横盘或缓慢上涨环境可能较适配，但不是存在一个保证最优的市场：持续大跌可能长期套牢，急涨可能反复错过上涨。每次卖 Put 应预留接股资金，卖 Call 应确认持股覆盖；“循环收租”不能代替总回报和回撤核算。
