# 期权交易检查清单

> 用于学习演练与逐笔复核。完成笔记或检查表，不代表已经证明策略盈利；先用模拟记录验证流程。

## 开仓前：观点必须能被检验

- [ ] 写清标的、价格区间、期限和事件，分别说明方向观点与波动率观点。
- [ ] 给出无效条件和退出计划；不只写“看涨”或“IV 高”。
- [ ] 核对财报、分红、公司行动和到期时间；若事件时间不明，记录为未知。
- [ ] 所有报价记录时间戳、实时/延迟状态、币种和数据源；不同时间的股票与期权报价不混算 IV。

## 合约与执行：看的是同一个产品

- [ ] 核对标的、Call/Put、行权价、到期、交易所/交易类别、乘数、交割物、美式/欧式、实物/现金结算。
- [ ] 多腿逐一检查方向与数量、净借记/净贷记及总金额；确认报价是每股还是整个组合。
- [ ] 查看当前 Bid/Ask、数量及报价新鲜度；Volume/OI 仅提供辅助信息，不能代替可成交深度。
- [ ] 使用能接受的限价并考虑滑点；中间价和 Last 不保证成交。组合订单也需核对成交方式、部分成交及腿间风险。
- [ ] 区分限价的执行约束与止损的触发逻辑；跳空时止损价不保证成交，止损限价可能无法成交。

## 损失、资金和集中度

- [ ] 根据 [[section08-strategy-payoffs|统一公式]] 重算到期盈亏平衡、最大损失、费用及张数。
- [ ] 同时计算保证金占用、现金/股票交割义务及交割后的持仓；保证金不是最大损失。
- [ ] 汇总同标的、同事件、相关行业和同到期的风险。分散行权价不等于分散风险。
- [ ] 对同一标的，用带符号数量×乘数汇总 Delta/Gamma/Theta/Vega；跨标的不直接相加等效股数。
- [ ] 设定账户层面的损失和保证金缓冲；未确定可靠上限时，不用软件 POP 或短期高胜率代替。

## 情景压力：联合变化，而非逐个孤立变化

| 情景 | 必须检查 |
|---|---|
| 股价大幅下跌 + IV 上升 | 卖 Put/信用价差损失、股票风险、保证金变化 |
| 股价大幅上涨 + 短 Call 指派 | 交股或股票空头、借券及对冲资金 |
| 财报跳空 + IV 回落 | 方向收益是否覆盖 Vega/Theta 与成本损失 |
| 到期贴近短行权价 + 盘后波动 | 哪些腿可能行权/指派，隔夜股票暴露 |
| 报价变宽 + 保证金上调 | 平仓能否成交，清算后是否仍有残余风险 |
| 断线 + 未确认订单 | 查询订单/成交后对账，禁止盲目重发 |

幅度应依据具体产品与事件设定，记录依据；小幅 Greek 近似不能代替跳空重估。跨到期结构分别冲击近月和远月 IV。缺乏估值数据时保留未知，不把空白当零。

## 持仓中与到期前

- [ ] 定期比较当前风险与原计划；展期要把旧仓平仓损益和新仓成本分别记录，不能掩盖亏损。
- [ ] 提前核对最后交易时刻、结算参考价及券商行权/DNE 截止；北京时间换算考虑美国夏令时。
- [ ] 不想承接交割时提前安排退出，并确认订单实际成交。
- [ ] 短腿被指派后重新核对股票、现金、剩余长腿和保证金；不假设保护腿已经自动处理。
- [ ] 到期后核对交易确认、成交、行权、指派、持仓和账户资金；标记任何未解释差异。

## 复盘最小记录

```text
日期 / 标的 / 策略 / 合约识别 / 报价时间与来源：
方向与波动率假设 / 事件 / 假设无效条件：
净权利金 / 乘数 / 张数 / 全部费用：
到期最大损失 / 保证金 / 交割义务 / 压力损失：
计划退出 / 实际成交 / 指派与剩余持仓：
已实现损益 / 未实现损益 / 数据缺失：
偏差原因 / 下一次流程改进：
```

账户曲线应包含未平仓损益、全部成本和资金进出调整。分别记录模拟结果与真实成交，报告样本量、回撤及尾部损失，不以权利金收入代替利润。
