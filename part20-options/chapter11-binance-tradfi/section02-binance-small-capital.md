# 为什么小资金也能参与股票期权

**买方先支付的是一段期限内的买卖权利价格（权利金），而不是100股股票的全部价款。** 因此初始支出可能很小，但买到的权利会到期，可能损失全部权利金。小额门票不代表小概率亏损，也不代表以后行权不需要钱。

本页均为虚构教学算术，金额按美元经济金额表示，忽略费用、税、汇兑及资金时间价值。账户实际扣款币种与规则见 [[section01-binance-stock-options|产品核查]]。这不是对某个标的、期限或方向的推荐。

## 先认识合约与四种角色

| 要素 | 含义与核查点 |
|---|---|
| 标的 S | 对应股票或ETF；标的ETF的期权不等于指数现金结算期权 |
| Call / Put | Call赋予按约定价买入标的的权利；Put赋予卖出标的的权利 |
| 行权价 K | 行权买卖标的的约定每股价格；不是支付的权利金 |
| 到期日 / 最后交易时间 | 权利的期限；最后交易、行权申请与失效时间可能不同 |
| 权利金 p | 期权本身的价格；可随标的、时间、IV等变化 |
| 合约乘数 m | 标准美股期权通常每张100股，常见 `报价×100×张数`；公司行动调整后可能不同 |
| 交割/行权方式 | 股票实物交割、可提前行权，不能套用欧式现金结算规则 |

标准单位与交割参见 [OIC/OCC：股票与指数期权区别](https://www.optionseducation.org/advancedconcepts/equity-vs-index-options)。拆股、并购等可能改变乘数或交付物，应读取具体合约而非只记“100”。

| 角色 | 初始现金流 | 行权或被指派时的关系 |
|---|---|---|
| Call买方 | 支出权利金 | 有权按K买入股票；行权需备齐价款 |
| Put买方 | 支出权利金 | 有权按K卖出股票；实物交割需核对可交付股票 |
| Call卖方 | 收取权利金 | 被指派时负有按K交付股票的义务 |
| Put卖方 | 收取权利金 | 被指派时负有按K买入股票的义务 |

买方拥有选择权，卖方承担义务。**卖出已有的买方持仓（卖平）不等于卖出新期权（卖开）**。买方在不借款且未转成股票头寸时，期权本身最大损失通常是已付权利金加费用；行权后股票风险应重新计算。裸卖Call理论亏损无上限，不属于本卷所述币安充分担保卖方权限。

## 小资金例子：100美元买的是权利

假设 `S₀=100、K=105、Call报价p=1、m=100、n=1张`：

- 直接买100股需要 `100×100=10,000`。
- 买1张Call初始权利金为 `1×100=100`，不是1元，也不是买到100股。
- 名义覆盖100股不等于始终具有100股的涨跌敏感度；有效方向敏感度还受Delta影响。

若到期权利的经济价值被成功实现，Call买方费用前净盈亏为：

```text
到期内在价值 = max(S_T - K, 0) × m × n
到期净盈亏   = [max(S_T - K, 0) - p] × m × n
到期平衡点   = K + p
```

| 到期股价S_T | 内在价值总额 | 减去已付100后的净盈亏 |
|---:|---:|---:|
| 100 | 0 | -100 |
| 105 | 0 | -100 |
| 105.5 | 50 | -50 |
| 106 | 100 | 0 |
| 110 | 500 | **+400** |

在110时，`(110-105)×100=500`是权利的**毛价值**，`500-100=400`才是费用前净利润；不能把500误写成净利润。105及以下会亏完100；105到106之间即使实值仍亏钱。费用会令平衡点进一步上移。

这是合约经济价值的计算，**不是币安到期会自动发放500现金的承诺**。股票实物交割且须遵守实际行权流程；未平仓、未有效行权或交割条件不满足，实值也可能失效，见 [[section04-binance-expiry-collateral|到期处理]]。

### 为什么行权还需要10,500

若选择行权买股票，需支付 `105×100=10,500`，取得100股；此前100权利金已发生，总经济支出10,600。若当时股票值11,000，净经济收益才是400，持有股票后仍承受股价下跌。

如果在到期前**卖出平仓期权**，处理的是合约，不需要为了这笔卖平先接100股或准备10,500。但必须有对手方、可接受价格并成功成交，深虚值或临近到期合约可能无买价。不能因“可以卖平”就假定一定能退出。

## Put与价内外

Put买方到期费用前净盈亏为 `[max(K-S_T,0)-p]×m×n`，平衡点 `K-p`。例如 `K=95、p=1、m=100`，到期90时内在价值500、净盈亏+400；到期95及以上损失100。股票最低为0的简单模型中，Put最大净收益为 `(K-p)×m×n`。

| 状态 | Call | Put |
|---|---|---|
| 实值 ITM | S>K | S<K |
| 平值 ATM | S约等于K | S约等于K |
| 虚值 OTM | S<K | S>K |

价内外只比较S和K；是否盈利还必须扣掉权利金、价差和费用。

## 到期前不能只用到期公式

到期前的期权价格通常可拆为内在价值和时间价值。卖平实现盈亏应使用**实际成交价**：`(卖平成交价-买开成交价)×m×n-总费用`。持仓估值用Bid、Ask或模型价会得到不同结果，Last不一定还能成交。

例如同样以1买入，之后实际以1.60卖平，1张费用前赚60；即便此时股价只有104、Call仍虚值，也可能因剩余时间与IV而有价格。反之股价上涨了，期权也可能因IV回落、时间流逝和价差而亏损。**到期平衡点106只适用于到期公式，不能用来判定所有到期前交易。**

## Greeks和IV：方向正确还不够

| 指标 | 买入普通Call/Put的常见表现 | 实际含义 |
|---|---|---|
| Delta | Call正、Put负 | 标的变动1单位时，期权每股价格的局部敏感度；不是固定杠杆或真实盈利概率 |
| Gamma | 通常正 | Delta随标的变化的速度；临近到期、接近平值时敏感度可能迅速变化 |
| Theta | 通常负 | 其他条件相近时，时间流逝损耗权利价值；衰减不是每天固定金额 |
| Vega | 通常正 | IV变化对价格的敏感度；注意平台按1个百分点还是其他单位显示 |
| Rho | 普通Call通常正、Put通常负 | 利率变化的敏感度；长期权利更应关注利率与股息假设 |

IV是从市场期权价格与模型反推的隐含波动率，描述波动定价，**不表达涨跌方向**。Greeks是局部模型估计，跳空或大幅IV变化时误差可很大；计算整张/组合影响要乘乘数、张数并使用持仓正负号。[OIC：Understanding Options Greeks](https://www.optionseducation.org/advancedconcepts/understanding-options-greeks)

财报、分红、并购及宏观事件可能抬高事件前的权利金；事件后即便方向判断正确，IV回落（IV Crush）也可能抵消内在价值增加。短期期权给走势实现的时间更少；深虚值期权便宜，往往意味着需要更大且更及时的有利变动。连续买多次小额期权仍可能累计大额损失。
