# Stock Options：从核查到开平仓

> 这是供本人逐项核对的学习说明。按钮位置和翻译可能随版本变化，以产品完整名称、订单动作和确认页为准。规则核验日：2026-10-16。

## 1. 操作前确认能交易什么

1. 确认入口为 **Stock Options**，不是加密Options、Commodity Options或TradFi Perpetuals；先读 [[section01-binance-stock-options|产品与规则]]。
2. 自行核对当地可用性、开户协议、身份及适当性要求、期权权限、风险披露；买方权限不能视同担保卖方权限。
3. 检查资金所在账户、可用与已冻结余额、扣款币种、交割资金/股票要求及费用。仅有100权利金，不代表有Call行权所需10,500。
4. 确认今天交易日历、ET时区、是否提前收市、该合约最后交易和行权截止。不要等到到期日才查。
5. 写出方向、幅度、期限、IV与事件假设；明确“若全部权利金损失能否承担”。有资金并不等于适合持有该合约。

## 2. 打开期权链，记录完整合约

一般路径为股票/TradFi入口 → 标的 → Options/期权链；入口名称不是承诺，界面缺少功能应核实权限。

按顺序核对：标的代码及名称 → 到期日 → Call/Put → 行权价 → 乘数 → 交付物 → 美式/欧式 → 实物/现金结算 → 合约币种。保存完整合约标识，不能只记“某股票105 Call”。

至少查看Bid/Ask、挂单数量、Last时间、成交量、持仓量、IV及Greeks。成交量和持仓量不能保证当前流动性；没有买价时，持仓的模型价值可能无法变现。比较标的和期权报价是否来自同一时点。

官方说明免费报价可能延迟15分钟，OPRA实时数据需激活。**不能拿15分钟前的Ask设定“立即可成交”的预期，也不能将延迟Last当作实时止盈止损触发价。** [Stock Options FAQ](https://www.binance.com/en/support/faq/detail/3dddc209bb564b448c0948fc4c5e6d80)

## 3. 分清四种订单动作

| 动作 | 作用 | 成交后的典型持仓变化 |
|---|---|---|
| Buy to Open，买入开仓 | 支付权利金建立买方持仓 | 长期权增加 |
| Sell to Close，卖出平仓 | 卖掉自己持有的同一合约 | 长期权减少；正常卖平不交割股票 |
| Sell to Open，卖出开仓 | 建立卖方义务 | 短期权增加；应有相应权限与抵押 |
| Buy to Close，买入平仓 | 买回自己卖出的同一合约 | 短期权减少；抵押释放须确认系统状态 |

“买Call”与“卖Put”可能都带正方向暴露，但现金流、风险与义务不同。持仓的到期日或K只要不同，就不是原合约平仓。平仓数量超过现有持仓可能被拒绝或产生另一种风险，必须在预览和成交后核查。

## 4. 买方限价开仓与订单核对

1. 选择买入开仓，输入张数与**每股权利金限价**（先确认界面报价单位）。例如1张、限价1、乘数100，预估权利金100，另加费用。
2. 预览完整合约、方向、数量、限价、总借记、币种、有效期及费用；对照日志，而非凭按钮颜色判断买卖。
3. 自行决定是否提交；限价单可能不成交或只成交部分。不要因未成交不断追价而突破事先预算。
4. 提交后查看订单状态、实际成交数量和均价、剩余挂单及持仓，直到相互一致。撤单申请发出不代表撤单成功，撤单途中仍可能成交。
5. 如报价或网络异常，先核对现有订单与成交记录，再决定后续动作，避免重复开仓。记录拒单原因，不通过更换产品绕过限制。

当前Stock Options及担保卖方资料均说明使用限价单；不假设市价、止损、OCO或组合单必然可用。[卖方上线公告](https://www.binance.com/en/support/announcement/detail/9fe16193d2ca442ca4d0fca0d608c910)

## 5. 持仓、止盈与退出

开仓前写清三类退出条件：观点失效、损失预算触及、计划时间/事件到来；另写止盈条件和到期前最迟处理时刻。条件应结合权利金、可执行买卖价、剩余时间与IV，不只看股票涨跌。

卖平时从现有持仓选择同一合约，确认 **Sell to Close**、数量和限价。未完成成交前仍有风险；部分平仓后剩余张数继续占用风险预算。核对成交后持仓归零/减少、剩余订单、费用与现金流水。

止盈止损是管理计划，**不是成交保证**：停牌、跳空、无买盘、价差扩大、延迟行情或接近收市都可能使退出偏离计划。限价止损若产品支持，也可能触发后无法成交。展期应分别记录旧仓平仓和新仓开仓，不能抹掉旧亏损。

## 6. 到期前单独核查

长期权卖平、主动行权、放弃/失效是不同结果；卖方买平、被指派、未被指派也是不同结果。Stock Options不能默认实值自动行权或系统一定代为卖平，具体流程见 [[section04-binance-expiry-collateral|到期与担保卖方]]。

如本意只交易权利金而不接股票，应提前安排卖平并预留异常处理时间；最后时刻无人接单并不等于风险消失。到期后仍要核对交割、冻结资金/股票释放和最终头寸。
