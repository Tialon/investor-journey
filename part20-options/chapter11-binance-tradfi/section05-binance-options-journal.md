# Stock Options检查清单与交易日志

> 可复制空表做纸面演练。完成检查表不代表策略盈利，也不等于获得交易权限。本卷规则核验日2026-10-16；每次使用仍须重查 [[section01-binance-stock-options|产品及规则版本]]。

## 开仓前

- [ ] 已确认Stock Options完整产品名、签约主体、地区资格、期权权限/适当性和披露；未把买方权限当卖方权限。
- [ ] 已核对标的、Call/Put、K、到期、最后交易时间、行权截止、乘数、交付物、币种和实物交割方式。
- [ ] 已记录ET与UTC时间、节假日/提前收市、财报、分红和公司行动；未知项目明确写出。
- [ ] 报价有时间戳和实时/延迟标记；理解免费15分钟延迟可能影响判断，当前Bid/Ask与数量可核查。
- [ ] 已算 `报价×乘数×张数`、总费用、可损失金额、到期平衡点和归零情景；没有把1元报价当1张总成本。
- [ ] 已测算标的下跌/横盘/上涨、IV回落、时间流逝与价差扩大的情景；方向猜对不保证盈利。
- [ ] 买方预算可覆盖整笔权利金损失；担保卖方有完整现金/股票抵押，清楚被指派后的头寸。
- [ ] 写明观点失效、止盈、损失预算、最迟退出时间和异常处理方案；退出成交不作保证。
- [ ] 已查看期权专属费表与订单预览，不把普通股票费率、理论成交价或零费用假设当成事实。

仓位演算可用 `张数上限=floor(单笔可承担损失预算÷每张压力损失)`；买方至少按权利金全部损失加费用核算。若预算连1张都不够，结果是0张，不能通过寻找更短、更虚值的合约强行满足数量。担保卖方还受抵押数量、股票风险和集中度限制，不能只按所收权利金算风险。

## 提交与持仓

- [ ] 订单动作是买开/卖平/卖开/买平中的正确一种，预览合约、张数、限价、借记/贷记和有效期。
- [ ] 委托、成交、持仓、资金冻结相互一致；部分成交与剩余挂单已记录。
- [ ] 撤单有成功确认；异常时先核对历史记录再决定是否重新提交。
- [ ] 每次复核仍使用新鲜报价；重大事件、IV变化或接近到期时重新检查假设。
- [ ] 若进行展期，旧仓损益与新仓风险分别记账，没有把旧损失隐藏在新成本中。

## 到期与交割

- [ ] 买方已决定卖平、有效行权或接受失效；知道币安股票期权不能默认实值自动行权。
- [ ] 自动卖平仅尽力，不依赖其保证退出；已核实具体行权截止，而非只记住正常收盘时间。
- [ ] 卖方知道不会自动平仓，已评估提前/到期指派、抵押股票交付与现金接股。
- [ ] 行权/指派后核对股票数量、资金变化和新的风险；抵押释放已到账，没有待处理义务。
- [ ] 保存最终成交单、交割记录与费用；持仓为0不等于所有交割都已完成。

## 每笔日志模板

| 字段 | 填写内容 |
|---|---|
| 记录编号 / 版本 | 日期、修改原因，保留开仓前原始假设 |
| 环境 | 纸面/模拟/真实；币安/IBKR；产品主体及权限核对日期 |
| 数据证据 | 官方规则URL/页面日期、行情来源、ET/UTC时间、延迟标记 |
| 合约 | 完整代码、标的、Call/Put、K、到期、乘数、交付物、币种 |
| 观点与反例 | 预期幅度/期限、IV与事件假设、观点失效条件 |
| 开仓报价 | 标的价；Bid/Ask/数量；Last时间；IV、Greeks及其单位 |
| 计划风险 | 权利金总额、费用、压力损失、抵押、账户及同标的集中度 |
| 退出安排 | 止盈/损失条件、时间退出、到期处理、无流动性与故障安排 |
| 实际执行 | 动作、张数、提交/成交时间、限价、均价、部分成交/撤单 |
| 最终结果 | 已实现与未实现分别列示；费用、换汇、交割股票及冻结余额 |
| 偏差复盘 | 方向/时间/IV/流动性/规则理解分别评估；下一次流程修正 |

单腿期权完成开平仓且无交割时，可按现金流对账：买方为 `(卖平均价-买开均价)×乘数×张数-总费用`，卖方为 `(卖开均价-买平均价)×乘数×张数-总费用`。有分批成交时逐笔加总；有行权、指派、股息和换汇时将股票与现金流水纳入，避免把行权价款全当期权亏损或重复计算权利金。

## 如何评价一次结果

先比较计划与证据，再看盈亏。一次赚钱可能来自侥幸跳空，一次亏损也不能单独否定全部流程。样本、费用、最大回撤、持有时间和未平风险要一致记录；权利金回报率、抵押资金回报率与整个账户回报率是不同分母，不能混用或把短期收益简单年化为承诺。

通用记录见 [[section05-trading-journal|期权交易日志]]、[[section06-execution-checklist|期权执行检查清单]]；本页补充币安特有的报价、到期及担保规则。
