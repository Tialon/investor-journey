# 期权链解读：报价、风险与推断边界

## 先确认合约，再看价格

期权链按到期日和行权价排列 Call/Put；界面可能左 Call 右 Put，也可能分栏或分组。先检查标的、到期日、币种、合约乘数与调整交割物，避免只看代码便默认每张 100 股。

IBKR 可在 TWS OptionTrader 中查看链，具体菜单随版本变化。产品选择、实时订阅、数据延迟与模型报价都应在当前界面核对。参见 [[section01-tws-options|TWS 操作笔记]]。

## 字段速查

| 字段 | 读法 | 不能推出什么 |
|---|---|---|
| Bid / Ask | 当前买方报价 / 卖方报价 | 显示价格不保证全部数量成交 |
| Bid / Ask Size | 当前报价对应数量 | 不代表深度无限或报价持续有效 |
| Last | 最近一笔成交价 | 不一定是当前可成交价 |
| Volume | 当日累计成交张数 | 不等于净买入、净开仓或机构方向 |
| Open Interest（OI） | 未平仓合约数量，通常按日更新 | 每张同时有多空双方，不表明谁主动或谁在对冲 |
| IV | 从价格及模型反推的波动率 | 不是真实未来波动，也不保证报价合理 |
| Delta / Gamma / Theta / Vega | 当前模型的局部敏感度 | 不保证跳空后的损益，不等于盈利概率 |

记录股票与期权的报价时间戳，确认是否同步、实时。期权休市但股票盘后变化时，旧期权报价搭配新股价会扭曲 IV。过期 Last、零 Bid、异常交叉报价均需另查。

## 成本与流动性

```text
中间价 = (Bid + Ask) / 2
绝对价差 = Ask − Bid
相对价差 = (Ask − Bid) / 中间价  （中间价必须 > 0）
合约权利金 = 每股报价 × 乘数 × 张数
```

Bid=2.40、Ask=2.60，按 Ask 买入一张乘数100的合约需 $260（未计费）。若立刻按不变 Bid 卖出，只得 $240，往返报价损失 $20，加上两次费用。按中间价 2.50 下限价单可能改善成本，也可能完全不成交。

“价差低于10%、成交量100、OI500”等仅是自定筛选参数，没有适用于所有标的和订单规模的固定门槛。综合看绝对/相对价差、显示数量、报价稳定性、订单大小和退出条件。开盘时即使活跃也可能价差很宽。

## Volume 与 OI 能说什么

- 双方都开仓，OI 增加；双方都平仓，OI 减少；一方开一方平，OI 不变。
- 很高的 Volume 可以来自同一批合约反复换手、多腿组合、展期或对冲。当天 Volume 高于前一日 OI 不证明知情资金正在买入。
- 次日 OI 变化只说明净未平仓变化，不能还原全部交易动机。
- OI 集中不保证支撑、阻力或吸引股价到某价位。Max Pain 是基于持仓的假设分析，不能独立当预测模型；GEX 还需要做市商仓位方向等额外假设。
- Put/Call 比率要写清按成交量还是 OI、产品范围与时间窗；保护性买 Put 与卖 Put 会有相同数量表现，不能把比率>1直接等同看跌。

异常活动适合列为研究线索，参见 [[section02-unusual-activity|异常活动分析]]，不要直接变成买卖信号。

## IV 比较应统一口径

同到期、可比 Delta 或虚实值下比较偏斜；跨到期同时考虑财报等事件。HV 是历史已实现波动，历史平均 IV 是另一项统计，二者不是同义词。高 IV 不自动意味着应卖，低 IV 也不证明便宜。

同一 K 的 Call 与 Put 反推 IV 不同，可能来自价差、不同时间戳、分红、模型或美式提前行权，不能直接当作“恐慌偏斜”的证据。更有意义的偏斜比较通常使用同到期不同执行价或可比 Delta 的合约。

## 教学快照：只练习解读

虚构标的 XYZ，S=100，同一到期、乘数100；下表手工构造用于报价和实虚值练习，不是模型校准数据或实盘行情，不用它反推 IV/交易优势。

| K | Call Bid/Ask | Call Volume/OI | Put Bid/Ask | Put Volume/OI |
|---|---|---|---|---|
| 95 | 6.90 / 7.10 | 400 / 1200 | 1.90 / 2.10 | 600 / 1800 |
| 100 | 3.90 / 4.10 | 1000 / 3000 | 3.90 / 4.10 | 1100 / 3500 |
| 105 | 1.90 / 2.10 | 650 / 1700 | 6.90 / 7.10 | 450 / 1400 |

以100 Call为例：ATM、内在价值0、中间价4、相对价差0.20/4=5%；按Ask买入成本$410。到期盈亏平衡104.10（未计费），到期股价102时即使实值仍亏$210。

95 Call 的内在价值5，按中间价7估算外在价值2；105 Put 同理。ATM行成交量高只说明该快照更活跃，不能证明你的订单一定成交或预测股价方向。Put OI 较高也不能单独证明市场看跌。

## 三道自测与参考答案

1. Bid=3.20、Ask=3.50、Last=3.10、OI=800，乘数100。按Ask买一张要多少？Last为何可能低于Bid？
2. 当天 Volume=3000、昨日OI=500，能否判定大量新买Call？
3. 买100 Call支出4.10，到期股价102，实值且盈利吗？

答案：1. $350加费用；Last可能是较早成交，当前报价已变化。2. 不能，还需次日OI、成交方向、组合腿和开平仓信息。3. 实值但亏$210加费用。
