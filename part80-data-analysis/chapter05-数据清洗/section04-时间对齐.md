# 时间对齐

## 至少保留三个时间

period_end是数据对应的期间，published_at是公开可知的时刻，retrieved_at是获取时刻。回测只能在published_at之后使用信息，不能按财报期末日期提前看到收入。

统一时区但保留原时区与交易所日历。股票盘后价格不能和休市期权报价直接反推即时IV；财报累计季度和单季度、不同财政年度也不能直接拼接。

更正/重述另留版本。研究现状可用最新版本，历史回测用当时可获得版本。自动连接数据时用“当时已发布且最近”的规则，人工抽查财报日前后，防止前视偏差。
