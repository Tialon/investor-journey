# 技术分析概述

## 定义

> **技术分析（Technical Analysis）** 是通过研究历史价格和成交量数据来预测未来价格走势的分析方法。其核心假设是：市场行为包容消化一切信息、价格沿趋势运动、历史会重演。

> **"技术分析是研究市场行为本身，而不是研究市场行为的原因。"** —— John Murphy

## 技术分析 vs 基本面分析

| 维度       | 技术分析          | 基本面分析        |
| -------- | ------------- | ------------ |
| **关注点**  | 价格走势、成交量、图表形态 | 财务报表、估值、行业前景 |
| **时间框架** | 短期到中期         | 中长期          |
| **核心问题** | 何时买卖？         | 买什么？         |
| **分析工具** | K线图、技术指标、画线工具 | 财务指标、估值模型    |
| **假设**   | 价格反映一切信息      | 市场可能错误定价     |

## 三大假设

### 1. 市场行为包容消化一切

所有影响股价的因素（基本面、政策、情绪等）都已经反映在价格中。因此，只需研究价格本身，无需深究原因。

### 2. 价格沿趋势运动

价格走势具有惯性，一旦形成趋势，往往会持续一段时间。技术分析的核心任务就是识别趋势并跟随趋势。

### 3. 历史会重演

市场参与者的心理和行为模式会重复出现。过去的图表形态和价格模式在未来可能再次出现。

## 技术分析的局限性

### ❌ 不适用的场景

- **突发事件**：黑天鹅事件（如疫情、战争）无法通过历史数据预测
- **长期投资**：技术分析更适合短中期交易，长期投资应以基本面为主
- **低流动性市场**：成交量过小的股票，技术分析可靠性降低
- **过度优化**：过度拟合历史数据可能导致未来表现不佳

### ⚠️ 常见误区

1. **技术分析是万能的**：没有任何方法能100%准确预测市场
2. **只看技术面**：忽视基本面可能导致买入劣质公司
3. **过度交易**：频繁根据技术信号交易会增加成本
4. **忽视风险管理**：技术分析只是工具，风险管理才是核心

## 技术分析的核心要素

```
技术分析
├── 价格分析
│   ├── K线图（单根K线、K线组合）
│   ├── 图表形态（头肩顶/底、三角形等）
│   └── 支撑位与压力位
├── 成交量分析
│   ├── 量价关系
│   └── 筹码分布
├── 趋势分析
│   ├── 移动平均线（MA/EMA）
│   ├── 趋势线
│   └── 通道线
└── 技术指标
    ├── 趋势指标（MACD、ADX）
    ├── 震荡指标（RSI、KDJ）
    └── 波动率指标（布林带、ATR）
```

## 学习路径建议

### 初级阶段（1-2个月）

1. 掌握K线图的阅读方法
2. 理解成交量与价格的关系
3. 学会识别支撑位和压力位
4. 掌握移动平均线的基本用法

### 中级阶段（2-4个月）

1. 深入学习MACD、RSI等常用指标
2. 掌握常见的图表形态
3. 学会综合运用多种技术工具
4. 建立自己的交易系统

### 高级阶段（持续学习）

1. 学习高级技术分析理论（波浪理论、江恩理论）
2. 开发量化交易策略
3. 结合基本面和技术面进行综合分析
4. 持续复盘和优化交易系统
