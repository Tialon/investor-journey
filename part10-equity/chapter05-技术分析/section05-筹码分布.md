# 筹码分布

## 一、什么是筹码分布

> **筹码分布**是指在某个时间点上，所有流通股按照买入价格的不同，在各个价位区间的分布情况。它反映了市场上所有持股者的成本结构。

### 筹码的本质

- 每一股股票都有一个买入成本
- 筹码分布显示了不同价位上有多少股票被持有
- 通过筹码分布可以了解市场的平均成本和套牢/获利情况

### 筹码分布图的构成

```
价格
  ↑
  │    ┌───┐
  │    │   │  ← 套牢筹码（红色）
  │    │   │
  │────┼───┼───── 当前价格
  │    │   │
  │    │   │  ← 获利筹码（绿色）
  │    └───┘
  │
  └────────────→ 筹码数量
```

- **红色部分**：当前价格上方的筹码（套牢盘）
- **绿色部分**：当前价格下方的筹码（获利盘）
- **筹码宽度**：该价位的筹码数量

## 二、关键指标解读

### 平均成本

平均成本是指所有持股者的加权平均买入价格。

**意义：**
- 当前价格 > 平均成本：多数投资者获利，市场情绪乐观
- 当前价格 < 平均成本：多数投资者亏损，市场情绪悲观
- 平均成本线是重要的心理关口

### 获利比例

获利比例是指当前价格下方的筹码占总筹码的比例。

| 获利比例   | 市场状态 | 操作建议        |
| ------ | ---- | ----------- |
| < 10%  | 极度超卖 | 可能见底，关注反弹机会 |
| 10-30% | 超卖   | 抛压减轻，可考虑买入  |
| 30-70% | 正常   | 观望为主        |
| 70-90% | 超买   | 获利盘较多，注意风险  |
| > 90%  | 极度超买 | 随时可能回调      |

### 筹码集中度

筹码集中度反映筹码的集中或分散程度：

- **集中度高**：筹码集中在少数价位，主力控盘
- **集中度低**：筹码分散在多个价位，市场分歧大

### 套牢盘与获利盘

| 类型 | 位置 | 心理 | 行为 |
|------|------|------|------|
| **套牢盘** | 当前价格上方 | 亏损，希望回本 | 回本时急于卖出 |
| **获利盘** | 当前价格下方 | 盈利，落袋为安 | 高位时获利了结 |

## 三、筹码峰的含义

### 什么是筹码峰

筹码峰是指筹码分布图上出现的明显的峰值区域，表示该价位有大量筹码集中。

### 筹码峰的类型

#### 1. 单峰密集

```
价格
  ↑
  │
  │      ┌───────┐
  │      │       │
  │      │       │
  │      │       │
  │      └───────┘
  │
  └────────────────→ 筹码数量
```

- 筹码集中在一个价位区域
- 表示市场成本趋于一致
- 变盘信号，可能大涨或大跌

#### 2. 双峰密集

```
价格
  ↑
  │  ┌───┐     ┌───┐
  │  │   │     │   │
  │  │   │     │   │
  │  │   │     │   │
  │  └───┘     └───┘
  │
  └────────────────→ 筹码数量
```

- 筹码集中在两个价位区域
- 两个峰之间形成"谷"
- 股价在两个峰之间震荡

#### 3. 多峰密集

- 筹码分散在多个价位区域
- 市场分歧大，趋势不明朗

### 筹码峰的支撑/压力作用

- **密集峰（支撑）**：股价下跌到筹码密集区，获利盘减少，抛压减轻
- **密集峰（压力）**：股价上涨到筹码密集区，套牢盘解套，抛压增加

## 四、实战应用

### 筹码分析流程

1. **调出筹码分布图**：在交易软件中查看筹码分布
2. **识别筹码峰**：找到筹码集中的价位区域
3. **计算平均成本**：了解市场整体成本
4. **判断套牢/获利**：分析当前价格相对于筹码的位置
5. **寻找支撑/压力**：利用筹码密集区判断关键价位

### 筹码选股策略

#### 策略一：底部单峰密集

**条件：**
- 股价经过长期下跌
- 筹码在低位形成单峰密集
- 获利比例接近0%
- 成交量极度萎缩

**操作：**
- 等待放量突破筹码峰
- 突破后买入
- 止损设在筹码峰下方

#### 策略二：突破筹码密集区

**条件：**
- 股价突破上方筹码密集区
- 成交量放大
- 获利比例快速上升

**操作：**
- 突破确认后买入
- 目标位看下一个筹码峰
- 止损设在原密集区上沿

#### 策略三：高位筹码松动

**条件：**
- 股价在高位
- 获利比例极高（>90%）
- 筹码开始分散

**操作：**
- 分批卖出
- 止盈设在支撑位
- 警惕主力出货

### 筹码分析的局限性

| 局限性      | 说明              |
| -------- | --------------- |
| **数据延迟** | 筹码数据通常有延迟       |
| **估算性质** | 筹码分布是估算，不是精确数据  |
| **忽略换手** | 筹码分布不考虑换手率的影响   |
| **主力欺骗** | 主力可能通过对倒制造假筹码分布 |

### 筹码分析的注意事项

1. **结合其他指标**：筹码分析需要配合K线、成交量等
2. **动态观察**：筹码分布会随时间变化
3. **关注换手**：高换手率会改变筹码分布
4. **识别主力**：通过筹码变化识别主力动向

## 五、moomoo 筹码功能使用

### 查看筹码分布

1. 打开股票K线图
2. 点击"筹码"按钮
3. 查看筹码分布图和相关指标

### 关键数据解读

| 指标 | 含义 | 应用 |
|------|------|------|
| 平均成本 | 所有持股者的平均买入价 | 判断整体盈亏状态 |
| 获利比例 | 获利筹码占比 | 判断超买超卖 |
| 压力位 | 系统计算的压力价格 | 卖出参考 |
| 支撑位 | 系统计算的支撑价格 | 买入参考 |
| 筹码集中度 | 筹码的集中程度 | 判断变盘可能 |

### 筹码实战案例

#### 案例一：苹果（AAPL）

- 平均成本：243美元
- 当前价格：278美元
- 获利比例：较高
- 压力位：281美元
- 支撑位：240美元

**分析：**
- 大部分筹码获利，有回调风险
- 接近压力位281，需要放量突破
- 下方支撑240，跌破可能继续下跌

#### 案例二：新股（如CRCL）

- 筹码集中在发行价附近
- 上方有大量套牢盘
- 需要消化套牢盘才能上涨
