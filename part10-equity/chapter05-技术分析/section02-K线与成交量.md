# K线与成交量

## 一、K线图基础

### 什么是K线图

K线图（Candlestick Chart）由一根根红绿蜡烛状的柱子组成，每根K线代表特定时间段内的价格变动。

### K线的时间周期

| 周期      | 每根K线代表 | 适用场景    |
| ------- | ------ | ------- |
| 1分钟K线   | 1分钟    | 超短线交易   |
| 5分钟K线   | 5分钟    | 短线交易    |
| 1小时K线   | 1小时    | 日内交易    |
| **日K线** | 1个交易日  | **最常用** |
| 周K线     | 1周     | 中期分析    |
| 月K线     | 1个月    | 长期分析    |

### K线的构成

每根K线由两部分组成：

```
    ┃  ← 上影线（最高价）
    ┃
  ┌─┴─┐
  │   │ ← 实体（开盘价与收盘价之间）
  │   │
  └─┬─┘
    ┃
    ┃  ← 下影线（最低价）
```

### 阳线与阴线（美股惯例）

| 类型     | 颜色  | 开盘价位置 | 收盘价位置 | 含义        |
| ------ | --- | ----- | ----- | --------- |
| **阳线** | 绿色  | 实体下端  | 实体上端  | 当天收盘 > 开盘 |
| **阴线** | 红色  | 实体上端  | 实体下端  | 当天收盘 < 开盘 |

**重要概念：** 阳线/阴线只代表当天开盘价与收盘价的关系，不代表与前一天相比是涨还是跌。判断涨跌需要与前一交易日的收盘价对比。

### 四个关键价格

| 价格  | 英文    | 位置    | 含义        |
| --- | ----- | ----- | --------- |
| 开盘价 | Open  | 实体一端  | 当日第一笔成交价  |
| 收盘价 | Close | 实体另一端 | 当日最后一笔成交价 |
| 最高价 | High  | 上影线顶端 | 当日最高成交价   |
| 最低价 | Low   | 下影线底端 | 当日最低成交价   |

## 二、常见K线形态

### 单根K线形态

#### 1. 大阳线/大阴线

```
大阳线          大阴线
  ┃              ┃
┌───┐          ┌───┐
│   │          │   │
│   │          │   │
│   │          │   │
└───┘          └───┘
  ┃              ┃
```

- **大阳线**：实体粗长，多头力量强势
- **大阴线**：实体粗长，空头力量强势

#### 2. 十字星

```
    ┃
    ┃
  ┌┴┐
  └┬┘
    ┃
    ┃
```

- 实体很短（开盘价≈收盘价）
- 上下影线较长
- 含义：多空博弈激烈，市场犹豫不决，可能预示反转

#### 3. 锤子线/上吊线

```
锤子线          上吊线
                ┃
                ┃
              ┌┴┐
              └┬┘
    ┃           ┃
    ┃
```

- **锤子线**：出现在下跌末端，下影线长，实体小，看涨信号
- **上吊线**：出现在上涨末端，形态相同但位置不同，看跌信号

#### 4. 射击之星/倒锤子线

```
射击之星        倒锤子线
    ┃           ┃
    ┃           ┃
  ┌┴┐         ┌┴┐
  └─┘         └─┘
```

- **射击之星**：出现在上涨末端，上影线长，看跌信号
- **倒锤子线**：出现在下跌末端，看涨信号

### K线组合形态

#### 1. 吞没形态

```
看涨吞没        看跌吞没
  ┃              ┃
┌───┐         ┌───┐
│ ┌─┼─┐       │┌─┼─┐
│ │ │ │       ││ │ │
└─┼─┘ │       │└─┼─┘
  │   │       │  │ │
  └───┘       └──┼─┘
                   ┃
```

- **看涨吞没**：阳线实体完全包裹前一根阴线，强烈看涨
- **看跌吞没**：阴线实体完全包裹前一根阳线，强烈看跌

#### 2. 乌云盖顶与刺透形态

- **乌云盖顶**：上涨中，阳线后出现阴线，阴线收盘价深入阳线实体一半以下，看跌
- **刺透形态**：下跌中，阴线后出现阳线，阳线收盘价深入阴线实体一半以上，看涨

#### 3. 早晨之星与黄昏之星

```
早晨之星（看涨）    黄昏之星（看跌）
    ┃                ┃
  ┌─┼─┐            ┌─┼─┐
  │ │ │            │ │ │
  └─┼─┘            └─┼─┘
    ┃                ┃
    ┃                ┃
  ┌┴┐              ┌┴┐
  └┬┘              └┬┘
    ┃                ┃
    ┃                ┃
┌───┐             ┌───┐
│   │             │   │
└───┘             └───┘
```

- 三根K线组合，中间为十字星
- 出现在趋势末端，预示反转

## 三、成交量分析

### 什么是成交量

成交量（Volume）是指在特定时间段内成交的股票数量。它反映了市场的活跃程度和多空力量的对比。

### 成交量柱状图

在K线图下方，通常会显示成交量柱状图：

- **绿色柱子**：买方占主导（收盘 > 开盘）
- **红色柱子**：卖方占主导（收盘 < 开盘）
- **柱子高度**：成交量大小

### 量价关系

量价关系是技术分析的核心，价格和成交量需要配合分析：

| 价格走势 | 成交量 | 形态名称     | 含义        | 操作建议  |
| ---- | --- | -------- | --------- | ----- |
| 上涨   | 放大  | **量价齐升** | 多头强势，趋势健康 | 持有/加仓 |
| 上涨   | 萎缩  | **量价背离** | 上涨动能不足    | 警惕反转  |
| 下跌   | 放大  | **放量下跌** | 空头强势，恐慌抛售 | 止损/观望 |
| 下跌   | 萎缩  | **缩量下跌** | 抛压减轻      | 可能止跌  |

### 成交量的特殊形态

#### 1. 天量天价

- 股价创新高的同时成交量创近期新高
- 可能是主力出货信号
- 需要警惕顶部形成

#### 2. 地量地价

- 股价创新低的同时成交量极度萎缩
- 抛压枯竭，可能是底部信号
- 需要等待放量确认

#### 3. 底部放量

- 长期下跌后突然放量
- 可能是有资金入场
- 结合价格走势判断是否见底

#### 4. 顶部放量滞涨

- 高位成交量放大但价格不再上涨
- 主力出货迹象
- 需要及时离场

## 四、实战应用

### K线分析要点

1. **看位置**：同样的K线在不同位置含义不同
2. **看组合**：单根K线意义有限，组合更可靠
3. **看成交量**：价格和成交量要配合分析
4. **看趋势**：K线形态要结合整体趋势判断

### 成交量分析要点

1. **量价配合**：健康的趋势需要成交量支持
2. **异常放量**：突然的放量往往预示变盘
3. **缩量特征**：缩量下跌可能见底，缩量上涨动能不足
4. **持续观察**：成交量需要持续跟踪，单日数据意义有限

### 常见错误

| 错误        | 正确做法          |
| --------- | ------------- |
| 只看单根K线做决策 | 结合多根K线和整体走势   |
| 忽视成交量     | 量价必须配合分析      |
| 逆势操作      | 顺势而为，不抄底摸顶    |
| 过度解读小周期   | 日K线更可靠，小周期噪音多 |
