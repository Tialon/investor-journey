# 支撑位与压力位

## 一、基本概念

### 支撑位（Support）

> **支撑位**是指股价下跌到某个价格水平后，买方力量增强，阻止股价继续下跌的价格区域。

支撑位的形成原因：
- 投资者认为该价格是"便宜"的买入机会
- 之前在该价位买入的投资者不愿意亏损卖出
- 空头在该价位获利了结，买盘增加

### 压力位（Resistance）

> **压力位**是指股价上涨到某个价格水平后，卖方力量增强，阻止股价继续上涨的价格区域。

压力位的形成原因：
- 投资者认为该价格是"高估"的卖出机会
- 之前在该价位被套的投资者急于解套卖出
- 多头在该价位获利了结，卖盘增加

支撑位 ────────────────────────── 6540

## 二、支撑位与压力位的识别方法

### 方法一：历史价格密集区

当价格在某个区域多次反弹或回落，形成波谷或波峰，该区域就成为支撑/压力位。

**识别步骤：**
1. 观察K线图，找到多次形成波谷（支撑）或波峰（压力）的位置
2. 用水平线连接这些点
3. 价格越多次在该位置反弹/回落，该支撑/压力越强

### 方法二：整数关口

整数关口（如100、200、1000等）往往成为心理支撑/压力位。

- 投资者倾向于在整数价格设定买卖指令
- 机构投资者也常在整数关口进行操作

### 方法三：前期高点/低点

- **前期高点**：成为压力位，因为之前在该价位卖出的投资者可能再次卖出
- **前期低点**：成为支撑位，因为之前在该价位买入的投资者可能再次买入

### 方法四：移动平均线

移动平均线可以作为动态的支撑/压力位：

| 均线周期 | 作用 |
|----------|------|
| MA20 | 短期支撑/压力 |
| MA60 | 中期支撑/压力 |
| MA120 | 中长期支撑/压力 |
| MA250 | 长期支撑/压力（年线） |

### 方法五：趋势线

```
上升趋势线（支撑）        下降趋势线（压力）
        ╱                      ╲
       ╱                        ╲
      ╱                          ╲
     ╱                            ╲
    ╱                              ╲
   ╱                                ╲
  ╱─────────────                    ─────────────╲
```

- **上升趋势线**：连接两个或多个上升的低点，作为支撑线
- **下降趋势线**：连接两个或多个下降的高点，作为压力线

### 方法六：斐波那契回撤

使用斐波那契数列（23.6%、38.2%、50%、61.8%、78.6%）计算回调/反弹的潜在支撑/压力位。

| 回撤比例 | 含义 |
|----------|------|
| 23.6% | 浅回调，强势延续 |
| 38.2% | 正常回调 |
| 50% | 中等回调 |
| 61.8% | 深回调，黄金分割 |
| 78.6% | 极深回调 |

## 三、支撑位与压力位的转换

### 转换原理

支撑位和压力位不是固定不变的，它们会相互转换：

- **支撑转压力**：股价跌破支撑位后，原来的支撑位变成压力位
- **压力转支撑**：股价突破压力位后，原来的压力位变成支撑位

```
压力位转支撑位
──────────────── 原压力位
      ╲
       ╲
        ╲
         ╲
          ╲──────────── 回踩确认，变成支撑
           ╲
            ╲
             ╲
```

### 转换的确认

1. **突破/跌破后回踩确认**：价格突破压力后，回踩到原压力位附近获得支撑
2. **成交量配合**：突破时放量，回踩时缩量
3. **时间确认**：价格在新位置站稳一定时间

## 四、突破与跌破

### 有效突破的判断标准

| 标准 | 要求 |
|------|------|
| **价格标准** | 收盘价突破压力位（不是盘中触及） |
| **幅度标准** | 突破幅度通常需要3%以上 |
| **时间标准** | 连续2-3个交易日站稳 |
| **成交量** | 突破时成交量放大 |

### 假突破的识别

假突破是指价格短暂突破后又回到原来的区间：

**假突破特征：**
1. 突破时成交量没有放大
2. 突破幅度很小（<3%）
3. 很快回落到原区间内
4. 没有后续买盘跟进

### 跌破的判断

与突破类似，跌破也需要确认：
1. 收盘价跌破支撑位
2. 成交量放大（恐慌性抛售）
3. 连续2-3个交易日未能收复

## 五、实战应用

### 支撑位买入策略

**条件：**
1. 股价回调到强支撑位附近
2. 出现止跌信号（如十字星、锤子线）
3. 成交量萎缩（抛压减轻）
4. MACD底背离（可选）

**操作：**
1. 在支撑位附近分批买入
2. 止损设在支撑位下方3-5%
3. 目标位看上方压力位

### 压力位卖出策略

**条件：**
1. 股价上涨到强压力位附近
2. 出现滞涨信号（如射击之星、上吊线）
3. 成交量放大但价格不涨
4. MACD顶背离（可选）

**操作：**
1. 在压力位附近分批卖出
2. 如果突破压力位，可以追涨买入
3. 如果回落，等待下一个支撑位

### 支撑/压力强度判断

| 强度因素 | 强支撑/压力 | 弱支撑/压力 |
|----------|------------|------------|
| 测试次数 | 多次测试 | 很少测试 |
| 停留时间 | 长时间停留 | 短暂触及 |
| 成交量 | 该位置成交量大 | 该位置成交量小 |
| 时间距离 | 近期形成 | 久远形成 |
| 整数关口 | 是整数关口 | 不是整数关口 |

### 常见错误

| 错误 | 正确做法 |
|------|---------|
| 忽视假突破 | 等待确认信号再操作 |
| 止损太紧 | 给价格足够的波动空间 |
| 只看一个支撑位 | 多个支撑位综合判断 |
| 忽视成交量 | 突破必须有量配合 |
| 逆势抄底 | 等待止跌信号出现 |

## 六、画线工具使用

### moomoo/TradingView 画线功能

1. **水平线**：标记支撑/压力位
2. **趋势线**：标记上升/下降趋势
3. **通道线**：标记价格运行通道
4. **斐波那契回撤**：自动计算回撤位

### 画线技巧

1. **连接关键点**：连接明显的波峰/波谷
2. **多次验证**：线条经过的点越多越有效
3. **适当延伸**：线条可以向前延伸预测未来
4. **定期更新**：随着价格变化调整线条
