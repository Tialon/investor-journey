# 图表形态

## 一、图表形态的分类

图表形态分为两大类：

| 类型 | 含义 | 代表形态 |
|------|------|---------|
| **反转形态** | 趋势即将反转 | 头肩顶/底、双重顶/底、圆弧顶/底 |
| **持续形态** | 趋势暂时休整后继续 | 三角形、旗形、楔形、矩形 |

## 二、反转形态

### 1. 头肩顶（Head and Shoulders Top）

```
        ╱╲  头
       ╱  ╲
      ╱    ╲
     ╱  ╱╲  ╲
    ╱  ╱  ╲  ╲
   ╱  ╱    ╲  ╲
  ╱  ╱      ╲  ╲
 ╱╲╱         ╲╱╲
左肩          右肩
─────────────────── 颈线
         ╲
          ╲  跌破颈线
           ╲
```

**特征：**
- 三个峰，中间最高（头），两边较低（左肩、右肩）
- 连接两个低点形成颈线
- 跌破颈线确认形态完成

**操作：**
- 右肩形成后警惕
- 跌破颈线卖出
- 目标跌幅 = 头到颈线的距离

### 2. 头肩底（Head and Shoulders Bottom）

```
         ╱
        ╱  突破颈线
       ╱
─────────────────── 颈线
 ╲  ╱         ╲  ╱
  ╲╱  ╲      ╱╲  ╱
       ╲    ╱  ╲╱
        ╲  ╱
         ╲╱
         头
```

**特征：**
- 与头肩顶相反
- 三个谷，中间最低
- 突破颈线确认形态完成

**操作：**
- 突破颈线买入
- 目标涨幅 = 头到颈线的距离

### 3. 双重顶（Double Top，M顶）

```
  ╱╲      ╱╲
 ╱  ╲    ╱  ╲
╱    ╲  ╱    ╲
      ╲╱
─────────────────── 颈线
        ╲
         ╲
```

**特征：**
- 两个高度相近的峰
- 连接中间低点形成颈线
- 跌破颈线确认

**操作：**
- 第二个峰未创新高时警惕
- 跌破颈线卖出
- 目标跌幅 = 顶到颈线的距离

### 4. 双重底（Double Bottom，W底）

```
        ╱
       ╱
─────────────────── 颈线
╱    ╱  ╲    ╱
╲  ╱    ╲  ╱
 ╲╱      ╲╱
```

**特征：**
- 两个深度相近的谷
- 突破颈线确认

**操作：**
- 突破颈线买入
- 目标涨幅 = 底到颈线的距离

### 5. 圆弧顶/底

```
圆弧顶              圆弧底
    ╱──╲               ╱──╲
   ╱    ╲             ╱    ╲
  ╱      ╲           ╱      ╲
 ╱        ╲         ╱        ╲
╱          ╲       ╱          ╲
```

**特征：**
- 形成时间较长
- 形态圆润，像碗或倒碗
- 一旦形成，反转力度较大

## 三、持续形态

### 1. 三角形（Triangle）

#### 上升三角形

```
───────────────── 水平压力线
 ╲    ╱╲    ╱
  ╲  ╱  ╲  ╱
   ╲╱    ╲╱
    上升支撑线
```

**特征：**
- 上边水平，下边向上倾斜
- 通常向上突破

#### 下降三角形

```
    下降压力线
 ╱    ╲╱    ╲
╱      ╱      ╲
───────────────── 水平支撑线
```

**特征：**
- 下边水平，上边向下倾斜
- 通常向下突破

#### 对称三角形

```
   ╲      ╱
    ╲    ╱
     ╲  ╱
      ╲╱
      ╱╲
     ╱  ╲
    ╱    ╲
```

**特征：**
- 上下边都向中间收敛
- 方向不确定，等待突破

### 2. 旗形（Flag）

```
上升旗形              下降旗形
      ╱                   ╱
     ╱                   ╱
    ╱  ╲               ╱  ╲
   ╱    ╲             ╱    ╲
  ╱      ╲           ╱      ╲
 ╱        ╲         ╱        ╲
╱          ╲       ╱          ╲
```

**特征：**
- 快速上涨/下跌后的小幅回调
- 形态像旗帜
- 通常延续原趋势方向

### 3. 楔形（Wedge）

#### 上升楔形

```
     ╱
    ╱ ╱
   ╱ ╱
  ╱ ╱
 ╱ ╱
╱╱
```

**特征：**
- 两条线都向上倾斜，但收敛
- 通常出现在下跌趋势中，是看跌形态

#### 下降楔形

```
╲╲
 ╲ ╲
  ╲ ╲
   ╲ ╲
    ╲ ╲
     ╲
```

**特征：**
- 两条线都向下倾斜，但收敛
- 通常出现在上涨趋势中，是看涨形态

### 4. 矩形（Rectangle）

```
───────────────── 压力线
│╲    ╱│╲    ╱│
│ ╲  ╱ │ ╲  ╱ │
│  ╲╱  │  ╲╱  │
│  ╱╲  │  ╱╲  │
│ ╱  ╲ │ ╱  ╲ │
╱    ╲╱    ╲
───────────────── 支撑线
```

**特征：**
- 价格在水平区间内震荡
- 上下边界清晰
- 等待突破方向

## 四、缺口（Gap）

### 什么是缺口

缺口是指价格图表上没有交易的区域，即相邻两根K线之间存在价格空白。

### 缺口的类型

| 类型 | 位置 | 含义 | 操作建议 |
|------|------|------|---------|
| **普通缺口** | 震荡区间内 | 通常会回补 | 观望 |
| **突破缺口** | 形态突破时 | 趋势开始 | 顺势交易 |
| **持续缺口** | 趋势中途 | 趋势延续 | 持有 |
| **衰竭缺口** | 趋势末端 | 趋势即将结束 | 警惕反转 |

### 缺口回补

- 大部分普通缺口会回补
- 突破缺口通常不回补
- 缺口位置可能成为支撑/压力位

## 五、形态交易策略

### 形态确认原则

1. **等待突破**：不要过早预测形态完成
2. **成交量配合**：突破时需要放量
3. **时间确认**：突破后站稳2-3天
4. **幅度确认**：突破幅度>3%

### 形态目标计算

| 形态 | 目标计算方法 |
|------|------------|
| 头肩顶/底 | 头到颈线的距离 |
| 双重顶/底 | 顶/底到颈线的距离 |
| 三角形 | 形态最宽处的距离 |
| 旗形 | 旗杆的长度 |

### 止损设置

| 形态 | 止损位置 |
|------|---------|
| 头肩顶 | 右肩上方 |
| 双重顶 | 第二个顶上方 |
| 三角形 | 形态内反向边界 |
| 旗形 | 旗形的反向边界 |

## 六、形态分析的局限性

### 常见问题

| 问题 | 说明 |
|------|------|
| **主观性** | 不同人可能识别出不同形态 |
| **滞后性** | 形态完成时价格已经移动 |
| **假突破** | 价格可能突破后又回落 |
| **形态失败** | 形态可能不按预期发展 |

### 提高准确率的方法

1. **多重确认**：结合其他技术指标
2. **成交量验证**：突破必须有量配合
3. **趋势配合**：形态方向与大趋势一致
4. **等待回踩**：突破后回踩确认再入场

## 七、实战案例分析

### 案例一：头肩顶反转

**背景：** 股价经过长期上涨

**形态：**
1. 左肩：股价创新高后回落
2. 头：股价再次创新高
3. 右肩：股价反弹但未创新高
4. 跌破颈线：确认形态完成

**操作：**
- 右肩形成时减仓
- 跌破颈线清仓
- 目标位：头到颈线的距离

### 案例二：上升三角形突破

**背景：** 股价在区间内震荡

**形态：**
1. 多次测试水平压力位
2. 低点逐渐抬高
3. 最终向上突破

**操作：**
- 等待突破确认
- 突破时买入
- 止损设在最后低点下方

### 案例三：旗形持续

**背景：** 股价快速上涨

**形态：**
1. 快速上涨形成旗杆
2. 小幅回调形成旗面
3. 再次向上突破

**操作：**
- 突破旗形上边界买入
- 止损设在旗形下边界
- 目标位：旗杆长度
