# 趋势与均线

## 一、趋势的基本概念

### 什么是趋势

趋势是指价格运动的方向。技术分析的核心目标就是识别趋势并跟随趋势。

### 趋势的三种方向

| 趋势       | 特征            | 操作策略      |
| -------- | ------------- | --------- |
| **上涨趋势** | 高点不断抬高，低点不断抬高 | 做多为主      |
| **下跌趋势** | 高点不断降低，低点不断降低 | 做空或观望     |
| **横盘震荡** | 高点和低点基本持平     | 区间交易或等待突破 |

### 趋势的时间框架

| 时间框架 | 持续时间 | 适用人群 |
|----------|---------|---------|
| 短期趋势 | 数天到数周 | 短线交易者 |
| 中期趋势 | 数周到数月 | 波段交易者 |
| 长期趋势 | 数月到数年 | 长期投资者 |

**重要原则：** 大趋势包含小趋势，交易时应顺应大趋势方向。

## 二、移动平均线（MA）

### 什么是移动平均线

移动平均线（Moving Average，MA）是将一定时期内的收盘价加以平均，然后连接成的一条线。它能够平滑价格波动，显示价格趋势。

### MA的计算方法

**n日移动平均线** = (第1天收盘价 + 第2天收盘价 + ... + 第n天收盘价) ÷ n

例如，5日MA = 最近5个交易日收盘价之和 ÷ 5

### 常用MA周期

| 周期 | 含义 | 适用场景 |
|------|------|---------|
| 5日（MA5） | 一周均线 | 超短线参考 |
| 10日（MA10） | 两周均线 | 短线参考 |
| 20日（MA20） | 月线 | 短中期分界线 |
| 60日（MA60） | 季线 | 中期趋势 |
| 120日（MA120） | 半年线 | 中长期趋势 |
| 250日（MA250） | 年线 | 长期趋势，牛熊分界线 |

### MA的基本用法

#### 1. 判断趋势方向

- **MA向上倾斜**：上涨趋势
- **MA向下倾斜**：下跌趋势
- **MA水平运行**：横盘震荡

#### 2. 支撑与压力

- **上涨趋势中**：MA是支撑线，股价回调到MA附近可能反弹
- **下跌趋势中**：MA是压力线，股价反弹到MA附近可能回落

#### 3. 金叉与死叉

```
金叉（看涨）           死叉（看跌）
      ╱╲                 ╲╱
     ╱  ╲               ╱  ╲
    ╱    ╲             ╱    ╲
   ╱  ╳  ╲           ╱  ╳  ╲
  ╱  ╱ ╲  ╲         ╱  ╱ ╲  ╲
 ╱  ╱   ╲  ╲       ╱  ╱   ╲  ╲
   MA5 MA10          MA5 MA10
  （短期上穿长期）    （短期下穿长期）
```

- **金叉**：短期MA上穿长期MA，买入信号
- **死叉**：短期MA下穿长期MA，卖出信号

### 多头排列与空头排列

#### 多头排列

```
        ╱ MA5
       ╱
      ╱ MA10
     ╱
    ╱ MA20
   ╱
  ╱ MA60
```

- 短期MA在上，长期MA在下
- 所有MA方向向上
- 强烈的上涨趋势信号

#### 空头排列

```
  ╲ MA60
   ╲
    ╲ MA20
     ╲
      ╲ MA10
       ╲
        ╲ MA5
```

- 长期MA在上，短期MA在下
- 所有MA方向向下
- 强烈的下跌趋势信号

#### 均线密集（缠绕）

- 多条MA交织在一起
- 趋势不明朗，市场在选择方向
- 等待均线发散后再操作

## 三、指数移动平均线（EMA）

### EMA与MA的区别

| 特性   | MA（简单移动平均） | EMA（指数移动平均） |
| ---- | ---------- | ----------- |
| 计算方式 | 简单算术平均     | 加权平均        |
| 权重分配 | 所有日期权重相同   | 近期数据权重更大    |
| 灵敏度  | 较低         | 较高          |
| 滞后性  | 较大         | 较小          |
| 适用场景 | 长期趋势判断     | 短中期交易信号     |
|      |            |             |

### EMA的计算

EMA = 收盘价 × 权重系数 + 前一日EMA × (1 - 权重系数)

其中，权重系数 = 2 ÷ (周期数 + 1)

### 常用EMA周期

与MA相同，常用5、10、20、60、120、250日EMA。

### EMA的特殊用法

1. **更灵敏的信号**：EMA对价格变化反应更快，适合短线交易
2. **减少滞后**：相比MA，EMA能更早发出趋势变化信号
3. **配合使用**：可以用EMA做信号，用MA做确认

## 四、MACD指标

### 什么是MACD

MACD（Moving Average Convergence Divergence）是基于EMA的指标，用于判断趋势的强弱和方向。

### MACD的构成

```
MACD图表
│
│  ┌─┐     ┌─┐
│  │ │     │ │
│──┼─┼─────┼─┼─────── 零轴
│  │ │ ┌─┐ │ │
│  │ │ │ │ │ │
│  └─┘ └─┘ └─┘
│
│  ─────●─────●───── DIF线
│       ╲   ╱
│        ╲ ╱
│         ●
│  ──────────────── DEA线
│
└────────────────── 红绿柱子（MACD柱）
```

| 组件 | 计算方式 | 含义 |
|------|---------|------|
| **DIF线** | 12日EMA - 26日EMA | 快线 |
| **DEA线** | DIF的9日EMA | 慢线（信号线） |
| **MACD柱** | (DIF - DEA) × 2 | 能量柱 |

### MACD的经典用法

#### 1. 金叉与死叉

| 信号 | 形态 | 含义 | 操作 |
|------|------|------|------|
| **金叉** | DIF上穿DEA | 看涨信号 | 买入/加仓 |
| **死叉** | DIF下穿DEA | 看跌信号 | 卖出/减仓 |

#### 2. 零轴上方/下方

| 位置 | 含义 |
|------|------|
| **零轴上方** | 多头市场，做多为主 |
| **零轴下方** | 空头市场，做空或观望 |

#### 3. 顶背离与底背离

```
顶背离（看跌）              底背离（看涨）

价格：  ╱╲  ╱╲             价格：  ╲╱  ╲╱
        ↑   ↑                       ↓   ↓
        新高  更高                    新低  更低

MACD：  ╱╲  ╱╲             MACD：  ╲╱  ╲╱
        ↑   ↑                       ↓   ↓
        高   更低                    低   更高
```

- **顶背离**：价格创新高，MACD没有创新高，预示上涨动能减弱
- **底背离**：价格创新低，MACD没有创新低，预示下跌动能减弱

#### 4. 红绿柱子

- **红柱放大**：多头力量增强
- **红柱缩小**：多头力量减弱
- **绿柱放大**：空头力量增强
- **绿柱缩小**：空头力量减弱

### MACD的局限性

1. **滞后性**：基于均线计算，信号可能滞后
2. **震荡市失效**：横盘震荡时频繁金叉死叉，产生假信号
3. **需要配合**：不能单独使用，需要配合其他指标

## 五、实战应用

### 趋势判断流程

1. **看长期趋势**：使用250日MA判断牛熊
2. **看中期趋势**：使用60日MA判断波段方向
3. **看短期趋势**：使用5/10日MA判断短期买卖点
4. **确认信号**：使用MACD金叉/死叉确认

### 均线交易策略

#### 策略一：均线多头排列买入

- 条件：MA5 > MA10 > MA20 > MA60，且都向上
- 买入点：股价回调到MA20附近获得支撑
- 止损：跌破MA60

#### 策略二：MACD金叉买入

- 条件：MACD在零轴附近金叉
- 买入点：金叉确认后
- 止损：死叉出现

#### 策略三：均线死叉卖出

- 条件：MA5下穿MA10，且MACD同步死叉
- 卖出点：死叉确认后
- 等待：均线重新多头排列

### 常见错误

| 错误 | 正确做法 |
|------|---------|
| 只看一个周期的均线 | 多周期配合分析 |
| 在震荡市频繁交易 | 等待趋势明确再操作 |
| 忽视MACD背离 | 背离是重要预警信号 |
| 逆势交易 | 顺势而为 |
