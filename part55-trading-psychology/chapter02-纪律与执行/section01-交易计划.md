# 交易计划

## 开仓前写完一页

```text
日期、标的、模拟/实盘、数据时间：
投资/交易假设及一手证据：
合理价格区间、入场条件、失效条件：
规模、计划损失、跳空压力损失、账户集中度：
退出条件、复核日期、禁止临场改变的规则：
尚缺哪些证据，缺失是否阻止开仓：
```

“跌了就补”“赚了再说”不是计划。止损价是执行条件，不能保证跳空后成交价；长期投资应同时检查经营假设而非只盯价格。下单前与 [[section05-总仓位控制]] 和 [[section06-execution-checklist]] 交叉检查。
